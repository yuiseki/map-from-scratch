# 未計測 example の計測（2026-10-29 JST）

`git pull --ff-only` 後の `main` で、`results/<id>/latest.json` がなかった 11 例を調べた。

## 方法

- 例25は `bin/mfs bake 25-akita-bear-sighting` 後、既存の `bin/mfs bench 25-akita-bear-sighting` を5回反復した。GPU は NVIDIA GeForce RTX 3060（Vulkan）。
- 例08・09・10・18〜24には `bench.ts` とシナリオがないため、既存のベンチマークハーネスではフレーム時間・GPU時間・予算判定を測れない。代わりにローカルの `bin/mfs serve` と隔離した headless Chromium で、各ページを新しいタブに開き、通信量、完了リクエスト数、画面表示、HTTPエラーを観測した。表の通信量は Chrome DevTools Protocol が報告した受信バイト数であり、配信元の総データ量ではない。
- スクリーンショットと機械可読の観測値は、Git管理対象外の `results/<id>/observed-2026-10-29.png` と `results/observational-2026-10-29.json` に保存した。

## 例25の正式ベンチマーク

| 指標 | 実測 | 予算 | 結果 |
| --- | ---: | ---: | --- |
| 初回描画 p50 | 5.5 ms | 400 ms 以下 | 合格 |
| CPU p95 | 1.735 ms | 1.0 ms 以下 | **不合格** |
| フレーム p95 | 3.22 ms | 16.6 ms 以下 | 合格 |
| コード gzip | 6,578 B | 8,000 B 以下 | 合格 |
| データ gzip | 196,187 B | 400,000 B 以下 | 合格 |

ピクセルの readback による3つの検証は全件合格。計測時のホスト load average は `22.89, 16.35, 12.84` で、CPU時間の比較にはこの負荷を考慮する必要がある。正式結果はローカルの `results/25-akita-bear-sighting/latest.json` に保存した。

この計測では、操作の正しさやアニメーション中の性能について、例08〜24の合格を主張しない。これらを正式な予算判定の対象とするには、各例に `bench.ts`、シナリオ、画素検証を追加する必要がある。
