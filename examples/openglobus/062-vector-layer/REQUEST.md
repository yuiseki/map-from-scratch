# openglobus-062-vector-layer

OpenGlobus の公式例「Natural Vector Layers」のように、3D 地球儀上に世界各国のベクター境界線および領土ポリゴンを高精細に投影描画したい。OpenGlobus 特有のダークスレート調グローブとシアン色のベクター境界線を用い、地平線裏面カリングを行いながらドラッグで回転、ホイールで拡大縮小でき、60 fps で滑らかに再描画すること。外部ライブラリなし、Canvas 2D で最速・最小で実装する。

## 元の例
- OpenGlobus: [Natural Vector Layers](https://sandbox.openglobus.org/examples/vectorLayer/vectorLayer.html)
