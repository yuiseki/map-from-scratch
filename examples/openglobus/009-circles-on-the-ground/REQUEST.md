# OpenGlobus "Circles on the ground" に対応する専用描画器

[OpenGlobus](https://www.openglobus.org/) の地面円の例は、球面上の中心とメートル半径から `Ellipsoid` 上に円を張り付けて描きます。

この実装は同じ考え方の円を、ベイク時に緯度ごとの経度圧縮（cos 緯度）を補正したリングとして生成し、Canvas 2D で陸地の上に半透明で塗ります。中心は東京 1,500 km、ニューヨーク 1,200 km、ロンドン 1,000 km です。ドラッグによるパンとホイールズームを持ち、円は地理座標に固定されて操作に追従します。

元例との同条件の速度・画面比較は未実施です。元例は WebGL の地球儀、この実装は正距円筒図法の Canvas 2D です。

## データと帰属

- 背景の陸地: Natural Earth 110m land（パブリックドメイン）。
- 円: 中心とメートル半径からベイク時に生成。

## 計測

`bin/mfs bench openglobus-009-circles-on-the-ground -n 3` を3反復した。画面は1024×768・DPR 1。Canvas 2D なので GPU 時間は取得できない（`gpu: n/a`）。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 22.7 ms | 300 ms 以下 |
| 再描画 p95 | 0.97 ms | 2.0 ms 以下 |
| フレーム間隔 p95 | 6.89 ms | 20 ms 以下 |
| コード gzip | 2,889 B | 5,000 B 以下 |
| データ gzip | 32,750 B | 120,000 B 以下 |

画面ピクセルと操作の検証7項目は3反復すべてで通った。

## 実装のメモ

- 地面円は緯度によって横方向の縮尺が変わるため、`dLon = r / (111320 * cos lat)` で経度方向を補正する。
- 半透明の塗りは海色・陸地色と混ざるので、検証は各色成分の差で行う。
