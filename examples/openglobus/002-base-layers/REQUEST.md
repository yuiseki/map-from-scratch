# openglobus-002-base-layers

OpenGlobus の Base Layers 例のように、UI の切り替えボタン（「OSM」と「Satellite」）でベースレイヤー（標準地図スタイルと衛星写真風ダークスタイル）を瞬時に切り替えられる地図を表示したい。ドラッグでパン、ホイールでズームでき、スタイル切り替え時も位置・ズームが保持されること。外部ライブラリなし、Canvas 2D で最速・最小で実装する。
