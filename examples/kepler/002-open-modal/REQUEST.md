# kepler-002-open-modal: kepler.gl Open Modal

## 依頼内容

kepler.gl の [Open Modal](https://docs.kepler.gl/examples/open-modal) と同じ意図で、ホスト画面上のボタンクリックからモーダルダイアログ内に kepler.gl 描画器を立ち上げ、開閉後も状態を維持しつつ、外部ライブラリ（React, Redux, deck.gl, Mapbox）なしで再現したい。

## 実装方針

1. **ホスト画面とモーダルダイアログの分離**:
   - 初期画面はホストアプリケーションのカード UI を表示し、モーダルは `display: flex` / `visibility: hidden` で初期化。
   - ボタンクリックでモーダルを表示し、`requestAnimationFrame` タイミングでキャンバスサイズをモーダル実寸に同期（`map.resize()`）。
2. **状態維持とクリーンなライフサイクル**:
   - モーダルを閉じても WebGL コンテキストやバッファ、カメラ位置（中心・ズーム・チルト）は保持。
   - 再度開いた際も再フェッチやバッファ再構築なしに即座に前回の視点で描画再開。
3. **画面読み戻し検証**:
   - 初期状態でのモーダル非表示検証。
   - モーダルオープン時のピクセル読み戻しによる地震点描画検証。
   - 閉じるボタンでの閉鎖検証。
   - 再オープン時の状態維持（ズーム値・点群数）検証。
