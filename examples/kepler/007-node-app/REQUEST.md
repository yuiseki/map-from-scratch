# kepler-007-node-app: kepler.gl Node App

## 依頼内容

kepler.gl の [Node App](https://docs.kepler.gl/examples/node-app) サンプルと同じ意図で、Node.js サーバーからエクスポートされた自己完結型レポート画面（上部レポートバナー、統計サマリー、ヒストグラム、ダウンロード導線）と WebGL2 地図描画器を、外部ライブラリ（React, Redux, deck.gl, Mapbox）なしで再現したい。

## 実装方針

1. **自己完結型エクスポートレポートレイアウト**:
   - 上部にサーバーエクスポートバナーを配置。
   - 左サイドバーに総レコード数、最大マグニチュード、発生頻度ヒストグラム、CSV/GeoJSON ダウンロード導線を整備。
2. **WebGL2 パイプライン**:
   - レポートレイアウト内に埋め込まれた WebGL2 地図キャンバスで 54,936 点を高速描画。
3. **画面読み戻し検証**:
   - レポートバナーおよびメタデータの存在検証。
   - 集計サマリー表示の検証。
   - 地震点群ピクセル読み戻し検証。
   - パン・ズーム性能の検証。
