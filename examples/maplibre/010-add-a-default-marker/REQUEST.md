# maplibre-010-add-a-default-marker: デフォルトマーカーの表示

## 依頼内容

> ワシントンD.C.（経度 -77.0369, 緯度 38.9072）に標準のマーカー（ピン）を1つ立てて、ドラッグでパン、ホイールで拡大縮小できる地図を表示したい。外部ライブラリなしで、最速・最小で。

元例: [MapLibre GL JS - Add a default marker](https://maplibre.org/maplibre-gl-js/docs/examples/add-a-default-marker/)

## 設計の意図と判断

1. **Canvas 2D を選択**
   - 元の MapLibre GL JS は 280 KB 以上の JavaScript と WebGL2 コンテキストを初期化して DOM マーカー要素をオーバーレイしますが、この依頼の本質は「1個のマーカーピンを地図上の特定座標に固定してパン・ズームする」ことです。
   - Canvas 2D を採用することで、WebGL2 のシェーダーコンパイルやバッファ生成コストをゼロにし、初回描画まで数ミリ秒の立ち上がりを実現しました。
2. **Path2D による即時ピン描画**
   - 外部 SVG アイコンファイルのネットワーク取得やデコード遅延を待つことなく、ベジェ曲線と円弧からなるティアドロップ形状（シアン `#3FB1CE`、白枠、内側の白丸）を直接パスで描画します。
3. **ベイク時の陸地事前投影**
   - Natural Earth 110m の陸地ポリゴンをあらかじめ Web Mercator 座標 `[0, 1]` に変換し、小数点6桁に丸めてベイクしています。

## 計測と検証

- **初回描画時間**: 陸地データの fetch から初回画面描画完了まで、ミリ秒単位で完了します。
- **マーカー位置のピクセル検証**:
  - `marker-visible-at-target`: 初期画面の中央にあるマーカー位置から `getImageData` でピクセルを読み戻し、MapLibre 標準ピンのシアン色が描画されていることを確認。
  - `marker-moves-with-pan`: 地図を (50px, 30px) 移動させた際、マーカーのピクセルが同期して正確に移動することを検証。
  - `marker-anchors-on-zoom`: 拡大縮小後も地理座標に対応するピクセルにピンが留まることを検証。
