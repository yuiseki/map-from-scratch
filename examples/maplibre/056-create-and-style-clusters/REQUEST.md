# MapLibre「Create and style clusters」の専用描画器

## 依頼

> 地震地点をズームに応じて集約し、件数を色・大きさ・数字で示したい。クラスタをクリックすると展開し、単点ではマグニチュードと津波情報を見たい。

[元例](https://maplibre.org/maplibre-gl-js/docs/examples/create-and-style-clusters/)が読み込む USGS の地震 GeoJSON 6,107 地点をそのままベイクする。背景には [Natural Earth](https://www.naturalearthdata.com/) の110m陸地と経緯線を使い、地名・道路・衛星画像は含めない。元例の `clusterRadius: 50` に合わせてズーム整数ごとに50ピクセル相当のセルへ集約する。元例の Supercluster とクラスタ境界・中心が完全一致する方式ではない。

## 設計

- 点の Web Mercator 座標・マグニチュード・津波フラグを16バイト/点に保存する。
- 低解像度の陸地を別 Canvas に描き、円と件数はその上に表示する。
- ズーム0〜14の集約結果を初回に一度作り、移動中は WebGL2 の点スプライトを1回の描画呼び出しで描く。ズーム段階が変わるときだけ GPU バッファを更新する。
- 件数ラベルと経緯線は別の Canvas2D に描き、クリック時には集約セルを分割できるズームへ移動する。
- 元の MapLibre 版との同条件比較は今後実施する。比較が完了するまで速度の優劣は主張しない。

## 計測

`bin/mfs bench maplibre-056-create-and-style-clusters --site` を3回反復した。GPUは NVIDIA GeForce RTX 3060（Vulkan）、画面は1280×800・DPR 1。6,107地点とNatural Earth 110m陸地を配信した。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回描画 p50 | 114.7 ms | 1000 ms 以下 |
| パン・ズーム中のフレーム p95 | 1.665 ms | 8.3 ms 以下 |
| パン・ズーム中の CPU p95 | 0.96 ms | 参考値 |
| パン・ズーム中の GPU p95 | 0.01434 ms | 参考値 |
| クラスタ展開時のGPUバッファ更新 p95 | 0.15 ms | 参考値 |
| コード gzip | 6,166 B | 12,000 B 以下 |
| データ gzip | 94,580 B | 150,000 B 以下 |

全地点の件数一致、クラスタ表示、展開、ズーム15での単点表示を画面読み戻しと状態比較で確認した。表示とドラッグ・クリックの操作感には目視確認も必要である。元の MapLibre 版との同条件比較はまだ行っていないため、速度の優劣は主張しない。
