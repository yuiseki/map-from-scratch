# maplibre-052: 地形つき地球儀の上のクマ出没ヒートマップ

MapLibre GL JS の例「Create a Heatmap layer on a globe with terrain elevation」と同じことを、外部ライブラリなしの WebGL2 で作りました。元例はカリフォルニアの地震を、Mapterhorn の地形と陰影の上にヒートマップとして貼り、71 度傾けて見せ、縮小すると大気の光をまとった地球儀になります。ここでは秋田県のクマ出没情報（クマダス、ツキノワグマ 23,306 件、2022〜2026 年）を、奥羽山脈を含む Mapterhorn の標高の上に貼っています。

## 見えるもの・操作

- 開始視点は秋田平野の上空から東北東の奥羽山脈を見下ろす、ズーム 8.7・傾き 70 度。地形は z9（約 117 m 画素）の標高から、段彩と北西からの陰影で描きます。海は Mapterhorn で標高ちょうど 0 m の場所です（八郎潟干拓地のような 0 m 未満の陸は陸のまま）。
- ドラッグで回転と傾き、Shift+ドラッグで移動、ホイールでポインタの下を保ったまま拡大縮小します。
- 半径と強度のスライダー、年の選択（すべて／2022〜2026）があります。年の選択は年ごとに並べた点の描画範囲を切り替えるだけです。
- 縮小すると地球儀になり、ズーム 2 から 0 にかけて元例と同じ割合（atmosphere-blend 1→0）で大気の光が出ます。

## しくみ

- ヒートマップ: MapLibre の heatmap シェーダと同じガウス核（GAUSS_COEF、ZERO で四角形の大きさを決める）を、地形の範囲を覆う 2048x2730 の R16F テクスチャへ加算ブレンドで描きます。地形の断片シェーダが範囲座標でこれを読み、99 パーセンタイルで割って対数に通してから（下の「分かったこと」）、元例の heatmap-color と同じランプに通します。密度は面の属性なので、尾根や谷に沿って曲がります。半径は元例と同じくズーム 0 で 1/10、ズーム 9 以上で指定値の画素数を、画面中心の縮尺で地上距離に直して使います。核が 32 テクセルを超えるときは縮小した部分だけに描き、縮小時の集計コストを抑えます。
- 地球儀: MapLibre と同じ中心縮尺（地球儀の半径 = worldSize / (2π cos 緯度)）の球をズーム 0.5〜12 のすべてで使います。平面への切り替えがないので縮小は連続です。秋田の範囲は 512x683 セルのメッシュ（頂点シェーダで標高テクスチャを読む）とスカート、世界は 1 度格子の球に z1 の粗い標高を貼り、秋田の範囲だけ捨てています。
- データ: 標高は Terrarium の小数バイトを捨てた 0.25 m 単位の 2 バイト可逆 WebP（2.05 MB、元タイルは 3.53 MB）で、ブラウザの画像デコーダで読みます。

## 分かったこと

- Terrarium の B バイト（1/256 m）は 117 m 格子では雑音で、可逆 WebP の大きさを押し上げます。0.25 m 単位で 42% 小さくなりました。1 m 単位なら 1.49 MB ですが、平野の陰影に段がつくので採りませんでした。PNG（ZLEVEL 9）は 2.82 MB でした。
- 元例と同じ clamp(強度 × 密度) の色付けでは、23,306 件の秋田平野がほぼ全面で飽和して赤一色になり、強度を 0.2 に下げても開始視点の熱の画素の 24.3% がランプの熱い端（密度 0.8 以上）でした。どこが密かが読めないので、色付けを変えました。集計した密度を「熱のあるテクセルの 99 パーセンタイル」Dref で割り、t = log(1 + 100x) / log(1 + 100)（x = 強度 × 密度 / Dref）でランプに通します。Dref は GPU で求めます。集計テクスチャを間引いて log2 のヒストグラム（224 区間）に加算ブレンドで数え、1x1 の断片シェーダが累積をたどります。CPU への読み戻しはありません。強度は色付けのときに掛けるので、元例と同じく密度の倍率として効き、既定値は元例の既定の 1 に戻しました。開始視点の熱い端は 6.6% になり、秋田市だけが赤く、谷筋が中ほどの色、点在する 1 件が淡い青で見分けられます。年を絞ると Dref もその年の密度に合わせて変わります。定数（P99、K=100、ヒストグラムの区間）は heat.ts の1か所にあり、シェーダと heat.test.ts が同じ値を読みます。
- 縮小した地球儀は開始視点の傾き 70 度のまま下寄りに見えます（元例も傾きを保ちます）。

## 未計測（2026-11-03）

利用者の指示で、計測は別の回に回しました。spec.yaml の予算（初回描画 1.5 s、回転・縮小・全域の frame_ms p95 16.7 ms、転送 3,000 KB、コード gzip 16 KB）と 7 つの check は書いてありますが、`bin/mfs bench` はまだ一度も走らせていません。開発サーバと Chromium で開始視点と縮小した地球儀を目視し、地形・陰影・ヒートマップ・大気の光が描かれることだけ確かめました。遠景の秋田の範囲外は z1 の粗い標高で、霞で隠していますが範囲の縁が見えることがあります。
