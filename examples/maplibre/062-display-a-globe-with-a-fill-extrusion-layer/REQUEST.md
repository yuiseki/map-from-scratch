# MapLibre: Display a globe with a fill extrusion layer

元の例（[Display a globe with a fill extrusion layer](https://maplibre.org/maplibre-gl-js/docs/examples/display-a-globe-with-a-fill-extrusion-layer/)、
`ref-repos/maplibre__maplibre-gl-js/test/examples/display-a-globe-with-a-fill-extrusion-layer.html`）は、
中心 (30, 40) の地球儀に手書きの矩形3つを `fill-extrusion` で押し出し、`GlobeControl` で地球儀と平面を切り替える。
ここでは目的（球面から外向きに押し出したポリゴンを持つ 3D 地球儀と、平面との切り替え）を保ったまま、
Natural Earth 1:10m admin 0（v5.1.1、パブリックドメイン）の 258 か国すべてを人口 POP_EST で押し出す。

## 見えるもの

- 宇宙の中の淡い色の海の地球儀。各国は高さと色（viridis）で人口を表す。尺度は平方根
  （t = sqrt(POP_EST / 最大)、最大は中国 1,397,715,000）。高さは 0.004 R + 0.16 R·t、中国で約 1,020 km。
  対数尺度では 1,000 万と 10 億が似た高さになり、線形では中国とインド以外が平らになるため。
- 凡例は描画と同じ `ramp.ts` から作る（目盛りは t = 0, 0.25, 0.5, 0.75, 1 の人口）。
- ドラッグで回転（押した地点がポインタについてくる）、ホイールでポインタ位置を保って拡大縮小、
  右上のボタンで地球儀と平面（正距円筒、40 度の固定ピッチ）を 700 ms かけて切り替える。
- ポインタを乗せる（タップする）と国名、日本語名、人口が出て、その国が明るくなる。
- URL の `#経度/緯度/距離[/flat]` で別の視点から開ける（例 `#100/30/3.5/flat`）。

## 設計

1. **格子で切ってから三角形分割する（bake.ts、grid.ts）。** earcut の三角形をそのまま球へ置くと、
   ロシアやカナダの長い三角形が平らな弦になって球に潜る。先にリングへ 3 度格子との交点を入れ、
   ポリゴンをセルごとに Sutherland–Hodgman で切ってから earcut にかける。セルの対角 4.24 度の弦のたわみは
   0.00068 R で、最小の押し出し 0.004 R の 1/6。交点を先に入れてあるので隣のセルとは同じ境界頂点を共有し
   （割れ目がない）、側面の上端も天面の縁と頂点単位で一致する。
2. **180 度線と極。** Natural Earth は 180 度線でリングを切り、南極は -90 度の線で閉じている。経緯度のまま
   三角形分割して球へ置けば、切れ目の辺は球面上でも隣のピースの辺と重なり、極の辺は極の1点に潰れる。
   その辺にだけ側面を立てない（mesh.ts の `isCut`）。チュクチとアラスカ、南極を中心にして目視で確かめた。
3. **1 つの頂点で2つの投影。** 頂点は int16 ×4（経度、緯度、国 id、天面か）。頂点シェーダーが球面の位置と
   平面の位置を作って t で補間する。平面は中心で球に接する z = 1 の面に正距円筒で置くので、中心での位置と
   縮尺が一致し、切り替えのアニメーションが素直になる。平面では世界を3つ並べて描く。
4. **色と高さはテクスチャ。** N×1 の RGBA32F（NEAREST、非フィルタ形式でも完全なテクスチャになる）。
   ホバーは uniform 1 個で、データは GPU 上で変わらない。
5. **陰影。** 天面は球の法線（平面では上向き）、側面は画面空間の微分から求めた面の法線。最初は天面も微分で
   求めたが、3 度セルごとの面が格子模様に見えたので天面だけ滑らかな法線にした。側面か天面かは flat な
   varying で渡し、側面の三角形の最後の頂点（WebGL の provoking vertex）を必ず地表側にしてある。
6. **当たり判定。** 同じ頂点シェーダーで id をオフスクリーンへ描き、ポインタの1ピクセルだけ scissor して
   読む。縁の向こうに立つ中国の天面や側面にも当たり、絵と食い違わない。

## データ

- countries.bin 1,010,364 B（gzip 344,389 B）: 天面 75,346 頂点・55,962 三角形、リング 1,188 本・53,843 頂点。
  countries.json 12,330 B。三角形の合計は海 14,400 ＋ 天面 55,962 ＋ 側面 107,424（読み込み時に作る）＝ 177,786、頂点 297,575。
- 添字の差分を u32 で持つと 1,346,136 B（gzip 364,796 B）。セルごとに分割しているので差分は最大 219 で、
  int16 にして 1,010,364 B になった。

## 途中の失敗

- 最初の海の色 (30, 62, 102) は、viridis の 0.25 付近（ロシア 1.44 億人で (59, 82, 139) 付近）に陰影をかけた
  色と見分けにくく、ロシアが海に見えた。淡い海 (196, 208, 222) に変えた。
- 距離 3.2 では 768 px の高さに対して縁の半径が 471 px になり、地球儀が画面からはみ出した。4.5（327 px）にした。
- 手元の playwright の Chromium は既定の GPU 設定で WebGL コンテキストを失い白い画面になった。
  `--use-angle=swiftshader` で描画を確かめた（計測には使わない）。
