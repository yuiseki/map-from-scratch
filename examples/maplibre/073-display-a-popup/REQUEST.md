# MapLibre: Display a popup

MapLibre GL JS の公式サンプル「[Display a popup](https://maplibre.org/maplibre-gl-js/docs/examples/display-a-popup/)」を写経し、外部ライブラリ（MapLibre / Mapbox 等）を使わずに最小・最速の専用描画器を作成してください。

## 依頼内容
1. 中心座標 `[-96.0, 37.8]`、ズームレベル `zoom: 3` で地図を表示する。
2. 指定座標 `[-96.0, 37.8]` にアンカーされた吹き出し型ポップアップ（白背景、ドロップシャドウ、下部突起、閉じるボタン「×」、内容「Hello World!」）を描画する。
3. ドラッグによるパンやホイールによるズーム操作時も、ポップアップ先端が正確に座標位置に追従する。
4. 閉じるボタンのクリックでポップアップを閉じ、外部ボタンから再オープン可能にし、ピクセル読み戻しで検証する。
