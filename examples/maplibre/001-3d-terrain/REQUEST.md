# maplibre-001-3d-terrain: 3D 地形立体標高モデル表示

## 依頼内容
MapLibre GL JS の公式サンプル「3D Terrain」を再現する。
2D 地図の枠を超え、富士山（標高 3,776m）の成層火山円錐・山頂火口（お鉢）・放射状浸食谷・山麓草原を含むリアルな 3D デジタル標高モデル（DEM）メッシュを生成し、傾斜法線による太陽光拡散反射ライティングと高度段彩（雪氷・溶岩荒原・針葉樹林・山麓緑地）、大気深度フォグを伴う透視投影でレンダリングする。
外部依存ゼロ、WebGL2 で最速・最小の描画器として実装する。

## 実装のポイント
- **3D 標高メッシュと段彩**:
  - $128 \times 128$ の高密度グリッド頂点（32,768 三角形）により滑らかな火山の稜線を表現。
  - 標高 $Z$ に応じた精密な高度段彩（山頂冠雪、火山礫荒原、深緑の亜高山帯樹林、淡緑の山麓草原）。
- **陰影と大気フォグ**:
  - 有限差分法で勾配 $(-\partial z/\partial x, -\partial z/\partial y, 1)$ を計算し法線ベクトルを導出。
  - 視点からの距離に応じた指数的大気フォグにより、遠方の山麓が青空の彼方へ自然に溶け込む空気遠近効果を実現。
