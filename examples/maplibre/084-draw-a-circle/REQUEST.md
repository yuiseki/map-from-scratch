# MapLibre "Draw a circle" に対応する専用描画器

[Draw a circle](https://maplibre.org/maplibre-gl-js/docs/examples/draw-a-circle/) は、`turf.circle` で作った半径 50 km の円ポリゴンを GeoJSON ソースとして追加し、半透明の青で塗る例です。

この実装は同じ中心（[-74.5, 40]）と半径（50 km）の円を、ベイク時に Web Mercator のリングへ変換して Canvas 2D で塗ります。背景は Natural Earth 110m の陸地で、ドラッグによるパンとホイールズームを持ちます。円は地理座標に固定され、操作に追従します。

元例との同条件の速度・画面比較は未実施です。元例は WebGL、この実装は Canvas 2D です。

## データと帰属

- 背景の陸地: Natural Earth 110m land（パブリックドメイン）。
- 円: 元例と同じ中心・半径からベイク時に生成。

## 計測

`bin/mfs bench maplibre-084-draw-a-circle -n 3` を3反復した。画面は1024×768・DPR 1。Canvas 2D なので GPU 時間は取得できない（`gpu: n/a`）。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 20.3 ms | 300 ms 以下 |
| 再描画 p95 | 0.94 ms | 2.0 ms 以下 |
| フレーム間隔 p95 | 8.54 ms | 20 ms 以下 |
| コード gzip | 2,508 B | 4,000 B 以下 |
| データ gzip | 31,090 B | 38,000 B 以下 |

画面ピクセルと操作の検証5項目は3反復すべてで通った。

## 実装のメモ

- 円はメートル半径のまま実行時に描かず、ベイク時にメルカトル座標のリングへ変換する。
- 半透明の塗りは背景色と混ざるので、検証は青成分と赤成分の差で行う。
