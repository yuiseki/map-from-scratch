# MapLibre: Center the map on a clicked symbol

MapLibre GL JS の公式サンプル「[Center the map on a clicked symbol](https://maplibre.org/maplibre-gl-js/docs/examples/center-the-map-on-a-clicked-symbol/)」を写経し、外部ライブラリ（MapLibre / Mapbox 等）を使わずに最小・最速の専用描画器を作成してください。

## 依頼内容
1. ニューヨーク、ロンドン、東京の3つのシンボル（ピン）を世界地図上に表示する。
2. シンボルをクリックすると、地図の中心がその都市へイージングしながら移動する。
3. 空の場所をクリックしてもカメラは動かない。
4. ドラッグでパン、ホイールでズームできる。
5. ピクセル読み戻しでピンの表示・クリックによる中心移動・空クリック・ドラッグ・ズームを検証する。

## 設計の意図と判断

1. **中心座標のトゥイーンだけ**
   - カメラはメルカトル座標の中心1点で表し、600 ms の easeInOutQuad で補間する。ピッチも方位も持たないので、カメラ行列は不要。
2. **`advance(ms)` と `setAnimating(false)`**
   - 計測時にタイマーへ依存しないよう、経過時間を外部から進められるようにした。同じフレームを何度でも再現できる。
3. **ドラッグでトゥイーンを破棄**
   - 移動中にユーザーが地図を掴んだら、その場でトゥイーンを捨てる。カメラが勝手に戻る競合を防ぐ。
4. **ピンは3本だけ**
   - スプライトアトラスやインスタンス描画を持たず、毎フレーム 3 本のパスを描く。

## 計測結果

## 検証チェック

- `symbols-visible`: 3都市のピン頭部が指定色。
- `click-centers-on-symbol`: ロンドンのクリックで中心がロンドンになる。
- `click-empty-does-not-move`: (700,620) のクリックで中心が不変。
- `click-other-symbol`: 東京のクリックで東京が中心になる。
- `drag-pans`: 40×20 px のドラッグで中心がその分動く。
- `wheel-zoom-keeps-point`: ピンを中心にしたズームでピンが動かない。

## データ

- Natural Earth 110m 陸地（パブリックドメイン）をベイク時に Web Mercator へ投影。

## 実装上の落とし穴

- ピンの当たり判定は頭部（半径8）と胴（三角形）をまとめた矩形で行う。先端だけで判定すると、頭をクリックしたときに反応しない。
- 中心を都市に合わせる際、`from + (to - from) * 1` は浮動小数の丸めで `to` と完全一致しないことがあるため、検証は 1e-9 の許容差で比較する。
