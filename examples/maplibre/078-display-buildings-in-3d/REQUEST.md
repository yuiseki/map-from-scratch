# maplibre-078-display-buildings-in-3d: 3D 建築群押し出し表示

## 依頼内容
MapLibre GL JS の公式サンプル「Display buildings in 3D」を再現する。
都市ブロックの建物フットプリントから、高さプロパティに基づき立ち上がる 3D 立体プリズム群（側壁および屋根ポリゴン）を生成し、ピッチ角・方位角を持った 3D 透視投影カメラと平行太陽光ライティングでレンダリングする。
汎用巨大エンジンを使わず、ゼロ依存の最小 WebGL2 シェーダーパイプラインで超高速に描画する。

## 実装のポイント
- **頂点押し出しと三角形分割**:
  - フットプリント外周から垂直壁面クワッド（三角形2枚）を生成し、外向き法線と高さに応じた接地アンビエントオクルージョングラデーションを付与。
  - 屋根ポリゴンは kits/earcut で三角形分割し、上向き法線 `(0, 0, 1)` を付与。
- **3D 透視投影と平行光源**:
  - ピッチ角 60°、方位角 -17° のカメラ視点から、Z-バッファ深度テストを有効化して正しい前後関係を描画。
  - 太陽光の指向性平行光源と環境光（アンビエント）を組み合わせた拡散反射シェーダー。
