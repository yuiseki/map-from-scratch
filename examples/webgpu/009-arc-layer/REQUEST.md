# 依頼: 全米人口移動 3D アーク (WebGPU)

全米の郡（County）間の人口移動フローデータを、WebGPU の 3D 放物線リボン（ArcLayer）としてリアルタイム立体描画してください。

## 要件
1. **3D 放物線リボン**:
   - 始点（流出元）と終点（流入先）の間の 2D 距離に応じたピーク高度を持つ 3D 放物線幾何を、WGSL 頂点シェーダー内で直接計算して描画すること。
   - アークの幅（リボン幅）をデバイスピクセル単位で制御し、始点から終点への色グラデーション（青 $\rightarrow$ 赤・マゼンタ）で流向を表現すること。
2. **単一インスタンス描画と高フレームレート**:
   - 何千本ものアークを WebGPU の 1 回のインスタンスドロー（`draw(stripVertexCount, arcCount)`）で描画し、60 FPS を維持すること。
3. **対話的操作と郡フィルタ**:
   - 3D 視点の自由な回転（yaw / pitch）、パン、ズーム操作に対応すること。
   - 選択された郡に関連する移動フローへの動的絞り込みに対応すること。
