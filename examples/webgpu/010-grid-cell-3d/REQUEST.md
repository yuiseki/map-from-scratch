# 依頼: パリ街路樹密度 3D グリッド (WebGPU)

パリ市内の約 20 万本の街路樹密度データを、WebGPU の 3D 直方体グリッド（GridCellLayer / 3D Grid Columns）としてリアルタイム立体描画してください。

## 要件
1. **3D 直方体インスタンス描画**:
   - 樹木密度に応じた高さを持つ 3D 直方体（キューブの上面・側面）を、太陽光ディレクショナルライティングと Reversed-Z で高速描画すること。
   - カバレッジ比率（グリッド間隔に対する柱の太さ）を制御できること。
2. **多解像度切り替え**:
   - 128m、256m、512m、1024m の各メッシュ解像度を動的に切り替えられること。
3. **対話的操作**:
   - 自由な視点回転（yaw / pitch）、移動、ズームが 60 FPS で動作すること。
