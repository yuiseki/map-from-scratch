# webgpu-005-taito-point-cloud: 台東区の点群 3D (WebGPU)

## 依頼内容

台東区の点群 PNG（産総研・地質調査総合センターの統合点群 PNG タイル）を表示したい。
（23-taito-point-cloud と同じ依頼を WebGPU で描画し、同じ条件で比べる）

## 実装方針

23-taito-point-cloud (WebGL2) と同じデータソース、同じタイル選択計画（表示用 5×5 タイル＋先読み 3×3 タイル）、同じ点群 PNG 1.0 復号、同じカメラ座標系と操作性を保ちつつ、描画パイプラインを WebGPU に刷新しました。

1. **頂点配置のインターリーブ最適化**:
   - 23 の WebGL2 版では位置（float32×3 = 12B）と色（uint8×3 = 3B）の 2 バッファ（計 15B）に分離していました。
   - WebGPU では 3 バイト頂点属性フォーマットが存在しないため、1 点あたり 16 バイト（float32×3 位置 + unorm8×4 色）のインターリーブ配置を採用し、単一 VBO にまとめました。

2. **三角形ストリップによるクワッド・インスタンシング**:
   - WebGPU の `point-list` トポロジーは仕様上 1 ピクセル固定であり、WebGL の `gl_PointSize` に相当する動的サイズ指定がありません。
   - そのため、各点を 4 頂点 `triangle-strip` のインスタンスとして描画し、頂点シェーダー内で 23 と全く同じ視点距離に応じたサイズ計算式（直径 1.2〜8.0 px）を適用してクワッドを展開。フラグメントシェーダー内で円形ディレクション計算（`dot(corner, corner) > 1.0` を discard）を行い、アンチエイリアスされた円盤を描きます。

3. **Reversed-Z による深度精度向上**:
   - 浮動小数点深度バッファ `depth32float` と Reversed-Z（near = 1.0, far = 0.0, depthCompare: 'greater'）を採用。
   - 近距離 0.5 m から遠距離 10 km まで、視点距離や仰角の変化による z-fighting や深度精度の劣化を排除しました。

4. **4x MSAA レンダリング**:
   - `sampleCount: 4` のマルチサンプルカラーテクスチャおよび深度テクスチャを確保し、キャンバステクスチャへ resolve。23 の WebGL2 版（`antialias: true`）と同等以上の滑らかなエッジ表現を実現。

5. **同一条件での計測と画面検証**:
   - `23-taito-point-cloud/bench.ts` の `measure` ハーネスをそのまま共有。
   - 雷門周辺の 25 タイルがロードされた後の 300 フレーム周回軌道（`orbit-path`）、上空 1.4 km 直下視点（`top-view`）、低空近接視点（`close-view`）の 3 経路で CPU 時間・フレーム時間・GPU 時間（timestamp-query）を計測。
   - 画面カバー率、色分散度、および CPU によるリファレンス splat 描画とのピクセル単位照合により、幾何・深度・色の描画精度を検証します。
