# REQUEST: WebGPU 3D Terrain Layer (Mt. Fuji)

## 依頼内容
富士山周辺（標高 3,776 m）の実測標高メッシュ（.terr 形式）を、WebGPU の 3D パイプラインと Reversed-Z 深度バッファを用いて超高速かつ写実的に描画したい。
法線ベクトルによる太陽光ライティング、標高に応じた自然なグラデーション着色（森林・溶岩岩肌・山頂残雪）、直感的なカメラオービット操作を 120fps/60fps で快適に体験できるようにしてほしい。

## 技術仕様
- プラットフォーム: Browser (WebGPU)
- データ形式: `17-fuji-terrain-3d` のベイク済みバイナリ (`fuji.terr`, Rice 符号化された多重解像度標高メッシュ)
- レンダリング方式:
  - 14万ポリゴンの 3D 地形グリッドメッシュ描画
  - 中央差分法による法線ベクトル計算とディレクショナル太陽光ライティング
  - Reversed-Z (`depth24plus`, `greater`) による遠景・近景の高精度深度テスト
