# Mapbox: Color Switcher

Mapbox GL JS の公式サンプル「[Color Switcher](https://docs.mapbox.com/mapbox-gl-js/example/color-switcher/)」を写経し、外部ライブラリ（MapLibre / Mapbox 等）を使わずに最小・最速の専用描画器を作成してください。

## 依頼内容
1. 中心 `[-60, 15]`、`zoom: 2.5` の地図を表示する。
2. 海・陸・ブラジル周辺の強調ポリゴンを 3 色のパレットで塗る。
3. Blue / Dark / Sunset のスウォッチをクリックすると、3 色がまとめて切り替わる。
4. パン・ズームしても選んだパレットのまま、色は地理座標に固定される。

## 設計の意図と判断

1. **配色は状態変数 1 個**
   - `paletteId` を切り替えて再描画するだけ。スタイル層や式評価器は持たない。
2. **色はテーブルから引く**
   - 3 パレット × 3 役割（海・陸・強調）を定数テーブルにし、描画ループはテーブル参照だけ。切り替えコストは再描画 1 回分。
3. **不透明 3 点で検証**
   - 海 (-30, 0)、陸 (-100, 40)、強調 (-60, -8) の 3 点を読み戻す。期待 RGB はベンチ側に独立に持ち、描画器のテーブルを読まない。
4. **カメラと直交**
   - 配色はカメラ状態と独立なので、パン・ズーム後も同じ地理座標が同じ色になる。検証は新しいカメラから投影し直す。
5. **背景は Natural Earth 陸地**
   - 大陸スケール（zoom 2.5）なのでラスタタイルは使わない。

## 検証チェック

- `default-palette-blue`: 海・陸・強調の 3 点が Blue パレット。
- `dark-palette-applied`: Dark クリックで 3 点が暗色系へ。
- `sunset-palette-applied`: Sunset クリックで 3 点が暖色系へ。
- `palette-persists-on-pan`: 60×40 px パン後も Sunset のまま。
- `palette-anchors-on-zoom`: zoom 3.5 でも 3 点が期待色。

## データ

- Natural Earth 110m 陸地（パブリックドメイン）をベイク時に Web Mercator へ投影。
- ブラジル周辺の矩形（経度 -70–-50、緯度 -20–5）をベイク時に投影。

## 実装上の落とし穴

- 3 点のうち強調ポリゴンの内側を選ぶとき、海のサンプルと重ならない座標にする。海 (-30, 0) は強調矩形の右辺（経度 -50）から 20° 東に離している。
- パレット切り替えは DOM クリック同期で再描画されるため、クリック直後の `getImageData` で新しい色が読める。`requestAnimationFrame` を待つ必要はない。
