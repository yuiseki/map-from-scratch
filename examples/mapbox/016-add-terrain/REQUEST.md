# mapbox-016-add-terrain: 3D 峡谷・花崗岩山岳地形表示

## 依頼内容
Mapbox GL JS の公式サンプル「Add Terrain」を再現する。
ヨセミテ渓谷のような氷河侵食 U 字谷、エル・キャピタンやハーフドームに代表される垂直の花崗岩モノリス岩壁、谷底の松林と蛇行河川からなる起伏に富んだ 3D 標高モデルメッシュを生成し、ゴールデンアワーの斜光線と大気ヘイズを伴う透視投影でレンダリングする。
外部ライブラリなし、WebGL2 で最速・最小の描画器として実装する。

## 実装のポイント
- **3D 峡谷メッシュとテクスチャリング**:
  - $128 \times 128$ の高密度グリッド頂点（32,768 三角形）により切り立った岩壁と谷底の緩やかな起伏を緻密に表現。
  - 斜面の傾斜角（法線ベクトル $n_z$）から崖面を自動検出し、岩肌のバフグレー、谷底の深い松林グリーン、清流のブルーを塗り分け。
- **夕陽ライティングと大気遠近**:
  - 西側岩壁を黄金色に照らし東側に深い陰影を落とすゴールデンアワーの太陽光設定。
  - 視点からの距離に応じた大気ヘイズ合成により、遠方の山並みが空へ溶け込む広大なスケール感を表現。
