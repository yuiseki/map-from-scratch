# Mapbox: Animate a marker

Mapbox GL JS の公式サンプル「[Animate a marker](https://docs.mapbox.com/mapbox-gl-js/example/animate-marker/)」を写経し、外部ライブラリ（MapLibre / Mapbox 等）を使わずに最小・最速の専用描画器を作成してください。

## 依頼内容
1. `[-96.0, 37.8]` にピンを1本置き、周期的に跳ねるアニメーションを表示する。
2. ピンの基準点（アンカー）は常に同じ地理座標で、跳ねは画面上のオフセットとして表現する。
3. ドラッグでパン、ホイールでズームでき、アニメーション中もピンはアンカーに追従する。
4. ピクセル読み戻しとアンカー座標で、跳ね・復帰・パン・ズームを検証する。

## 設計の意図と判断

1. **跳ねはスクリーン座標の y オフセット**
   - 地理座標は固定し、`26 * |sin(πt/700ms)|` を引くだけ。毎フレームの投影計算はアンカー1点で済む。
2. **`advance(ms)` による決定的な時間**
   - rAF を止めて時間を進められるようにし、位相に依存する検証を再現可能にした。
3. **影で高さを表現**
   - アンカーの楕円影を先に描き、ピンをその上に描く。跳ねていることが一目で分かる。
4. **背景は Natural Earth 陸地**
   - 大陸スケール（zoom 3）なのでラスタタイルは使わない。

## 検証チェック

- `marker-starts-at-anchor`: 静止時に先端 = アンカー。
- `marker-bounces-up`: 350 ms 後に 26 px 上。
- `marker-returns-to-anchor`: 700 ms で元に戻る。
- `marker-follows-pan`: 50×30 px のパンでアンカーも同じ量だけ動く。
- `marker-anchors-on-zoom`: zoom 4.5 で投影座標と一致。
- `wheel-zoom-keeps-point`: アンカー中心のズームで動かない。

## データ

- Natural Earth 110m 陸地（パブリックドメイン）をベイク時に Web Mercator へ投影。

## 実装上の落とし穴

- 影をピンの後に描くと、静止時にピンの先端を隠す。影を先に描く。
- 1周期ちょうどの `sin(π)` は 0 ではなく 1.2e-16 程度になるため、復帰の検証は `< 0.01 px` で比較する。
