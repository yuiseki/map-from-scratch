# Mapbox: Add an image (animated)

Mapbox GL JS の公式サンプル「[Add an image (animated)](https://docs.mapbox.com/mapbox-gl-js/example/add-image-animated/)」を写経し、外部ライブラリ（MapLibre / Mapbox 等）を使わずに最小・最速の専用描画器を作成してください。

## 依頼内容
1. 中心 `[0, 0]`、`zoom: 2` の世界地図を表示する。
2. `[0, 0]` に脈打つドットを置く。外側の輪は 1 秒周期で半径 15 → 50 CSS px に広がりながら不透明度 1 → 0 で消える。
3. 内側の赤い円（半径 15 CSS px、白い縁）は常に同じ。
4. ドットはズームしても画面サイズを保ち、パンすると地図と一緒に動く。

## 元例との差分

- 元例は `StyleImageInterface` で 200×200 の ImageData を毎フレーム作り直し、`map.triggerRepaint()` で再描画する。ここでは Canvas に 2 つの円を直接描き、同じ式（半径・不透明度・線幅）を CSS px で再現する。
- 背景は Mapbox のベクター地図ではなく Natural Earth 陸地塗り（ズーム 2 の世界スケール）。
- 位相を `setPhase(t)` で固定できるようにし、時間に依存する描画を決定的に検証できるようにした（通常は自走）。

## 設計の意図と判断

1. **ピクセルではなく円を描く**
   - 200×200 のピクセルバッファを毎フレーム作ると 1 フレーム 160 KB の書き込みとコピーが無駄。arc 2 回と fill 2 回で同じ見た目になる。
2. **フェードは外輪の不透明度**
   - 半径 `15 + 35t`、不透明度 `1 - t`。検証は海洋色との source-over 合成式で期待値を独立に計算し、環の内側と外側を同時に読む。
3. **位相の固定と自走の両方を検証**
   - 固定した位相で半径と色の式を確かめ、もう一方で自走中に位相が実時間で進み、その位相の半径で描かれていることを確かめる。
4. **画面サイズのドット**
   - symbol アイコン相当なので、ズームしても半径は変わらない。周囲の地図だけが拡大する。

## 検証チェック

- `map-rendered-at-target`: サハラが陸地、大西洋が海。
- `dot-core`: 位相 0.4 で中心が rgba(255,100,100,255)。
- `ring-expands-with-phase`: t=0 では半径 24 px に何もなく、t=0.5 では半透明の環が届く。
- `ring-fades-with-phase`: t=0.9 で同じ半径の赤成分が t=0.5 より 15 以上小さい。
- `dot-follows-pan`: 120×60 px パンで中心が動き、旧位置は海洋色。
- `dot-keeps-screen-size-on-zoom`: zoom 5 でも同じ位相の環の半径が不変。
- `animation-runs-live`: 自走中に 250 ms で位相が +0.25 進み、描かれた環の半径が式と一致。

## データ

- Natural Earth 110m 陸地（パブリックドメイン）を Web Mercator へ投影。ドットは画像アセットなしで描画。

## 実装上の落とし穴

- 元例の半径は 200 px 画像上の値。pixelRatio 2 のアイコンとして描くなら **CSS px に半分にする**。半分化を忘れるとドットが 2 倍になり、半径の式と画素が一致しない。
- 位相の読み取りと画素の読み取りは同じ同期ブロックで行う。フレームをまたぐと、読んだ位相とキャンバスの内容がずれる。
- 検証の期待半径も描画器と同じ式（CSS px）で書く。片方だけ半分にすると、描画が正しくても失敗する。
