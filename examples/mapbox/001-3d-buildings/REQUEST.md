# mapbox-001-3d-buildings: 3D 摩天楼押し出し表示

## 依頼内容
Mapbox GL JS の公式サンプル「3D Buildings」を再現する。
都市ブロックの建物フットプリントデータから、各ビルの高さに応じた 3D プリズム群（側壁および屋根ポリゴン）を押し出し生成し、夜間ダークテーマの中で発光するルミネセンス屋根と指向性月光ライティングでレンダリングする。
外部依存ゼロ、WebGL2 で最速・最小の描画器として実装する。

## 実装のポイント
- **夜間スタイリングと発光アクセント**:
  - 各摩天楼の屋根にネオンシアン・エレクトリックブルー・アンバーの発光色を配置。
  - 側壁は地面側から上層階にかけてのアンビエントグラデーションと月光シェーディング。
- **カメラとインタラクション**:
  - ピッチ角 45°、方位角 -17.6° の斜め視点からスムーズな回転・傾き操作に対応。
  - Z-バッファ深度テストにより建築群の正しい遮蔽関係を高速に維持。
