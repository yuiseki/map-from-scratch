# mapbox-044-dancing-buildings: 音で踊る東京駅のビル

## 依頼

Mapbox GL JS の公式サンプル「Animate 3D buildings based on ambient sounds」
(https://docs.mapbox.com/mapbox-gl-js/example/dancing-buildings/) を、外部ライブラリなしの WebGL2 で作る。
建物は PLATEAU の実データ (東京駅のまわりの 13,051 棟) にし、音はマイクか内蔵のリズムにする。

元の例は、ニューヨークの建物を高さで 16 の fill-extrusion 層に分け、マイクの AnalyserNode
(fftSize 32、-90〜-10 dB、平滑化 0.85) の 16 ビンで層 i の高さを `10 + 4i + bin[i]` に置き換え、
地図の光を `hsl((now / 100) % 360, min(50 + avg / 4, 100)%, 50%)`、強さ `min(1, avg / 256 * 10)` にし、
方位を `now / 500` 度で回し続ける。マイクは読み込み時にすぐ求める。

## 作ったもの

- 建物: PLATEAU 2025 (千代田区・中央区) の 3 次メッシュ 9 枚の LOD1。外形は lod1Solid の底面、高さは立体の高さ。
  1 本の頂点バッファと 1 本のインデックスバッファ、地面も同じバッファに入れて drawElements 1 回。
- 踊り方: 頂点は z を持たず、建物の高さと「屋上かどうか」と帯を持つ。頂点シェーダが屋上を
  `高さ x (1 + 1.5 x level[帯])` に上げる。毎フレーム送るのは 16 個のレベル、行列、光の色 (uniform) だけ。
  レベル 0 では本当の高さで立つ (元の例と違い、高さを置き換えない)。
- 帯の決め方: 東京駅からの距離の輪。輪の境は建物の距離の 16 分位で、どの輪も 816 棟。
  低い周波数 (ビン 0) が中心、高い周波数が外側なので、拍は中心から外へ広がって見える。
- 色: 元の例の光の式をそのまま `lightOf` に置き、建物の灰色にその光を足す。帯のレベルが高い建物はその光で明るくなる。
- 音: 「マイクで踊らせる」でマイク、「リズムを鳴らす」で内蔵のリズムを鳴らし、どちらも本物の AnalyserNode を毎フレーム読む。
  何もしなければ、内蔵のリズムを無音で解析した表で踊る (マイクの許可もユーザー操作も要らない)。
  リズムは種 44 の 2 小節 (120 BPM の 16 分): キック (正弦の周波数を下げる)、スネア (ノイズの帯域通過と三角波)、
  ハイハット (ノイズの高域通過)、矩形波のペンタトニック。音声ファイルはない。
- カメラ: 方位は元の例と同じ毎秒 2°で回る。ドラッグで移動 (つかんだ地面がポインタについてくる)、
  右ドラッグか Shift+ドラッグで回転と傾き、ホイールでポインタの下を中心にズーム。

## わかったこと

- OfflineAudioContext.suspend() で止めて AnalyserNode を読む方法は、headless Chromium で 1 回約 100 ms かかった
  (10 回で 1,055 ms、50 回で 4,717 ms)。表の 500 行で 50 秒になるので、描き終えたサンプルに Web Audio 仕様の解析
  (Blackman 窓、32 点 DFT、平滑化、デシベル) を JS で当てた (`audio.ts` の `analyse`、テストはトーンが自分のビンに出ること、
  無音が 0、音が止まると数行かけて減ること)。描画と解析で約 340 ms。
- 等幅の輪では帯 0 が 10 棟、最外の帯が 4,690 棟になった (中心は線路と皇居側で建物が少ない)。分位の輪にした。
- 元の例の解析設定では内蔵のリズムのバイト値が 60〜218 で下がりきらず、全部の建物が常に 1.4〜2.3 倍で立った。
  0.4 で切ってから伸ばす (`levelOf`) と拍が見える。
- PLATEAU の measuredHeight は LOD1 の高さと p50 0.9 m 違い、-9999 (不明) が 470 棟ある。名前つきでも
  「区立城東小学校 235.2 m」のように明らかにおかしい値がある。描くのは幾何と合う LOD1 の高さ。
  グラントウキョウサウスタワーは LOD1 199.3 m、measuredHeight 209.5 m。グラントウキョウノースタワーは LOD1 92.5 m (実際は約 205 m)。
- 各区の zip のメッシュには、その区の建物しか入っていない。メッシュ 9 枚の範囲でも港区などの建物は描かれない。
