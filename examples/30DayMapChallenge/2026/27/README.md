# 27 · New tool — WebGPU census map

東京都千代田区の2020年国勢調査「0～14歳人口」を、250m（4分の1地域メッシュ）ごとに描く専用 WebGPU 地図です。WebGPU compute がカメラごとに各セルの投影矩形、画面外判定、人口階級を計算し、その出力バッファを WebGPU のインスタンス描画へ渡します。CPU Canvas/別エンジンへのフォールバックはありません。

ドラッグで移動、ホイールで拡大縮小し、セルをクリックするとメッシュコード、元の文字列値、状態、表・列コードを確認できます。凡例は人口ありの階級、明示的な0、秘匿 `*`、表に行がないメッシュ、値が利用できない状態を分けています。表に行がないセルは `no-row`、値は `null` として保存し、0には変換しません。秘匿値も `value: null` と元の `rawValue: "*"` を保ちます。

## データ

- 地域: 東京都千代田区（全国地方公共団体コード `131016`）
- セル選択: 行政界ポリゴン（JGD2000 / EPSG:4612）を DuckDB Spatial / PROJ の `ST_Transform` で JGD2011（EPSG:6668）へ変換してから、中心点が内部または境界上にある全体の250mメッシュを採用します。メッシュは行政界で切らず、値を面積按分しません。
- 国勢調査日: 2020-10-01
- 表: `T001142`「人口及び世帯（JGD2011）」
- 使用列: `T001142004`「0～14歳人口 総数」
- CRS / メッシュ: JGD2011 経緯度。JIS X 0410 の10桁メッシュコードを定義式から復号します。セル幅は緯度7.5秒、経度11.25秒です。
- 付随属性: 原文の `HTKSYORI`, `HTKSAKI`, `GASSAN` を各国勢調査行に保持します。
- 帰属表示: 出典：政府統計の総合窓口(e-Stat)「令和2年国勢調査」（総務省統計局）を加工して作成。行政界の出典は、e-Stat「令和2年国勢調査」の小地域境界を加工した `yuiseki/jp-admin-2026-09`、CC BY 4.0。

2020年当時のメッシュ統計です。現在の人口、個人の位置や移動を示すものではありません。年齢別内訳の `*` は秘匿された値で、集約先に加算された値です。行政界と国勢調査メッシュの測地系を PROJ で統一してからセル中心を判定し、表示セル自体は境界でクリップしません。

## ファイル

- `bake.ts`: ローカルの e-Stat Parquet と行政界から決定的な `cells.json` / `stats.json` を生成
- `mesh.ts`: メッシュ復号・値状態・選択・ピッキング・シリアライズ検証
- `renderer.ts`: WebGPU compute 投影・分類・可視判定とインスタンス描画
- `main.ts`, `index.html`, `style.css`: 操作・アクセシブルな凡例と出典
- `bench.ts`: compute 出力と画面読み戻しを含む WebGPU 計測・検査

## 実行

```sh
bin/mfs bake 30DayMapChallenge-2026-27
bin/mfs test
bin/mfs bench 30DayMapChallenge-2026-27 -n 3
```

ブラウザベンチは `xvfb` と WebGPU の実 GPU が必要です。ソフトウェア GPU や WebGPU 非対応時はエラー表示とし、別描画器へ切り替えません。
