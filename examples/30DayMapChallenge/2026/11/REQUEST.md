# Day 11 · Senses: Sound

## 制作依頼と成果

公式のお題は「How do you hear something? How do you map a soundscape? Noise pollution mapped?」です。東京23区の道路と鉄道をもとに、場所ごとの音の景色を地図と合成音で表します。実測騒音の公開データを使った地図ではありません。

データは OpenStreetMap の東京23区 2026-08-31 固定スナップショットです。道路 163,329 ways と鉄道 8,004 ways を取得し、道路種別・鉄道種別ごとの重みを掛けた線長を320×320セルに集計しました。道路のセルは54,883、鉄道のセルは8,400です。線形を約28 mごとにサンプリングするため、これは線密度のモデルであり、現地の音圧、建物による遮蔽、交通量、時間帯を表しません。デシベル換算もしていません。

色は道路を橙、鉄道をシアンで重ねます。選択した地点の道路値はフィルター付きノイズ、鉄道値は低周波オシレーターの音量・周波数に別々に反映します。音源はブラウザー内で Web Audio API により生成し、録音や外部音源を取得しません。地図をクリックして地点を選び、ボタン操作後に再生します。東京駅・新宿駅・渋谷駅・上野駅のショートカットもあります。

## 出典と条件

- `hf:osm-tokyo23-src-2026-08` の `planet_osm_line.parquet` を使用。スナップショットは2026-08-31、座標はEPSG:3857です。
- 元データおよび派生グリッドは ODbL 1.0 の対象です。帰属表示は © OpenStreetMap contributors とし、ページに ODbL と著作権ページをリンクしています。
- 網羅範囲は東経139.55–139.92度、北緯35.52–35.82度の矩形です。東京23区外を含む境界上の空セルもあり、行政界で切った地図ではありません。
- 音は線種別の重み付き密度から作る合成表現です。騒音の測定値、音響伝播予測、現地録音、dB値として解釈しないでください。

## 実装と計測

- ベイク時に対象道路・鉄道路線を選び、線分を約28 m間隔で標本化して道路・鉄道の2つの uint16 チャンネルへ集計します。出力は410 KBです。
- 実行時は独自の TypeScript / Canvas 2D 描画器で2チャンネルをラスタライズします。ドラッグで移動、ホイールで拡大縮小し、クリック地点の値を選択します。
- Web Audio API は道路の低域フィルタノイズと鉄道の低周波正弦波を別チャンネルで合成します。音声再生はユーザー操作後に開始します。
- TDD テストは道路種別の相対重み、距離減衰、合成音パラメータ、グリッドのエンコード・デコード、地点セルのチャンネル参照を検証します。
- Chrome/Xvfb、1280×800、3回計測: 道路163,329 ways、鉄道8,004 ways、道路54,883セル、鉄道8,400セル。初回描画 p50 62.29 ms、描画CPU p95 0.055 ms、フレーム p95 0.315 ms、コード gzip 7,571 B、データ gzip 79,700 B。予算と5つのブラウザ検査は全て PASS。
- 計測スクリーンショットは `results/30DayMapChallenge-2026-11/screenshot.png` にあります。
