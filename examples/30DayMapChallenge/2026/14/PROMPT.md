# Day 14 map brief / creation prompt

Create a map for **30DayMapChallenge 2026 · 14 Borgesian map**. The official theme is “A map so detailed it becomes the territory. Inspired by Borges' On Exactitude in Science.” Use the frozen, real OpenStreetMap 2026-08-31 polygon snapshot for Tokyo, not generated imagery or invented geometry.

Make the scale itself the subject. Draw the actual OSM building footprints from one explicitly named, small Tokyo window in their source EPSG:3857 coordinates. Provide a whole-window overview and a pan-able detail viewport. Let the reader calibrate the physical display with a standard 85.60 mm payment-card-width reference. Only after calibration, offer a **ground-scale 1:1** view: correct Web Mercator's local scale by `cos(latitude)` and map each local ground metre to one measured physical metre on screen. State that this is a local approximation over a small window, because Earth is curved and EPSG:3857 scale changes with latitude. If the browser/display scale cannot be calibrated, label the view “screen scale unknown” and never claim it is physically 1:1.

The calibrated detail window should reveal the unsettling mismatch between a complete mapped building footprint and the tiny part of the actual territory that can fit on a monitor at 1:1. Show a clear scale bar in physical units, a crosshair/selection coordinate, and the overview's current detail window. Permit switching to an explicitly non-physical overview for navigation. Keep uncalibrated and calibrated states visually distinct.

Use a purpose-built renderer (Canvas 2D or WebGL) and custom camera/hit testing; no MapLibre, Leaflet, or other runtime map engine. Preserve source building geometry without decorative basemap imagery. Do not imply that OSM is a legal survey or that its geometries are ground truth. Document the exact extract bbox, source snapshot, ODbL attribution and processing, that clipped extract bounds are not official administrative boundaries, and the local projection/physical calibration assumptions. Make controls keyboard-accessible and usable without precise pointer gestures.

Before implementation, write tests for scale calibration, latitude correction, coordinate-to-screen transform, zoom anchoring, clipping, and the encoded geometry format. Check the selected source extent and building count against the frozen GeoParquet; record those figures and browser measurements. Do not use image generation.
