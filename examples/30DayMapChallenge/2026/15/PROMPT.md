# Day 15 map brief / creation prompt

Create a map for **30DayMapChallenge 2026 · 15 Inside out** using real public data; there is no fictional-map constraint. Make a genuine east-west terrain section at 42.25°N across eastern Hokkaido and the Pacific: deliberately reverse the GEBCO elevation sign so bathymetry rises above mean sea level and land falls below it. This visible inversion must be the map's central idea, not an ornamental effect.

Use the local 15 arc-second GEBCO_2026 GeoParquet extract for 143°–146°E. Preserve the selected source row values and longitude order. Add real 2025 M4.5+ USGS ComCat hypocenters in a clearly disclosed 0.5° latitude-wide slab around the section. Share the longitude axis, but render catalog depths on a separate, downward-increasing axis; do not treat the catalog depth datum as the GEBCO elevation datum, imply that events occurred at the transect itself, or claim that the data proves tectonic causality. Make point size indicate magnitude. Provide a vertical-exaggeration control, labels, a local ground-distance ruler, horizontal pan/zoom, keyboard navigation, and selectable USGS event links.

Use a dedicated Canvas 2D renderer with no runtime map framework or generated imagery. Bake only the profile cells and matching catalog events into a small self-contained data file. Attribute GEBCO using its full 2026 citation and URL; credit USGS ComCat and link selected events. Explain that 15 arc-seconds is grid spacing and not a claim about source-measurement resolution, that GEBCO values are relative to mean sea level, and that the USGS selection is magnitude-limited and spatially sliced.

Before implementation, test sign inversion, depth-axis direction, sampled endpoint stability, local distance, input validation, and drawing-pixel checks. Bake and report the real data range and count. Benchmark the actual browser canvas, inspect the resulting screenshot, and correct any visual or coordinate errors before recording results.
