# Day 03 — Polygons

Compare countries by their 2024 total population. Fill each country polygon on a
world map with a logarithmic color scale so that small and large populations
remain distinguishable, and mark countries with no joined value separately.

Population data: World Bank World Development Indicators, `SP.POP.TOTL`, 2024.
The selected catalog file has 217 country codes; 213 join Natural Earth's
`ADM0_A3` codes. The data source list for this indicator includes UN World
Population Prospects, national statistical offices, Eurostat, and the UN
Statistics Division. The World Bank does not endorse this copy.
