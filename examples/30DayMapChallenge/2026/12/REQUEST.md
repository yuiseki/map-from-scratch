# Day 12 · Power

## 制作依頼と成果

公式テーマ「Power」を、電力へのアクセス率がどう変わってきたかを比較する地図にしました。World Bank World Development Indicators の `EG.ELC.ACCS.ZS`（総人口に占める電力アクセス人口の割合）を1990–2024年で表示します。これは発電量や電源構成、送電網、停電頻度を表すデータではありません。地図を架空の地域に限定する条件はないため、出典と意味を確認できる実在の国別統計を採用しました。

2024年の値はNatural Earthの国ポリゴン212か国に結合し、1990年は96か国に値があります。258か国の形状を表示し、値のない国は0%と区別したNo Data色にします。年スライダーと再生ボタンで変化を追い、ドラッグとホイールで地図を操作できます。

## 出典と条件

- World Bank WDI 2026-10-01固定スナップショットの `EG.ELC.ACCS.ZS` 年次値を使用します。データにはCC BY 4.0とWorld Bank所定の紛争解決条項が適用されます。帰属文を画面に表示し、World Bankがこの複製を承認していないことも明記します。
- 国境形状はNatural Earth 10m Admin 0 countries v5.1.1です。Public Domainとして配布され、出典リンクを表示します。国コード `ADM0_A3` とWDIのISO3コードを結合キーにします。
- 電力アクセス率は各国の人口アクセス割合です。国ごとの調査・推計の差、データ欠損を含み、国境線や実際の供給品質・信頼性を意味しません。

## 実装と計測

- ベイク時にEqual Earth投影後の国ポリゴンを簡略化し、座標を `EQG1` 量子化バイナリへ格納します。35年の国別系列は欠損を保った `PWR1` バイナリです。258か国・4,274ポリゴン・4,293リング・84,805頂点を出力します。
- 実行時はCanvas 2DとDedicated Workerを使います。WorkerがPath2Dを保持し、年別の塗り分けをOffscreenCanvasでラスタライズします。メインスレッドは完成ビットマップを合成するため、パン・ズーム時に国境パスを描き直しません。
- ブラウザ検査では1990/2024年の結合数、既知国値、欠損値、画面上の日本とDRCの色、出典と注意書きを確認します。ピクセル検査前にWorkerの該当年描画完了を待ちます。
- Chrome/Xvfb、1280×800、3回計測: 初回描画 p50 262.4 ms、パン・ズーム frame p95 0.88 ms / 描画CPU p95 0.055 ms、年変更 frame p95 68.11 ms / 呼び出しCPU p95 0.11 ms。3回すべて予算と4つのブラウザ検査がPASS。データ gzip 346,550 B、コード gzip 8,705 B。
- 計測スクリーンショットは `results/30DayMapChallenge-2026-12/screenshot.png` にあります。
