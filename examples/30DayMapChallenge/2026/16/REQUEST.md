# Day 16 · Collaborative map

渋谷の約1 km²で、2025年にOpenStreetMapの建物へ記録された編集を月ごとに地図化します。格子にまとめた編集件数を月の累積として表示し、任意のセルを選ぶと新規・形状変更・属性変更などの内訳を確認できます。編集者の名前やIDは使わず、編集件数を投稿者数や品質評価として扱いません。

出典はohsome API v1の履歴抽出です。地物の重心を約38 × 46 mのセルに集計するため、マークは作業場所の厳密な形状ではありません。APIが位置を返さない削除記録は地図に載せません。OpenStreetMapへの帰属とODbL 1.0の表示を付けます。
