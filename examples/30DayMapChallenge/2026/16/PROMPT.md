# Day 16 map brief / creation prompt

Create a map for **30DayMapChallenge 2026 · 16 Collaborative map** from the real, public history of OpenStreetMap, a database built through community contributions. Do not invent geography, treat AI as a friend/coauthor, rank editors, or expose editor identity. Do not claim that the API distinguishes manual from automated edits.

Use the ohsome API v1 historical contribution extraction. Query only the fixed Shibuya AOI `139.696,35.650,139.706,35.660` (about 1 km²), dates `2025-01-01` through `2026-01-01`, and filter `building=*`; use `/v1/contributions/centroid`, request only contribution types and clipped geometry. The approved request returned HTTP 200 with 52,781 bytes and 162 features. Ten deletion records have no point geometry. Bake only the coordinate/time/type aggregates; discard OSM element and changeset identifiers, tags, and all person-related metadata.

Make a bespoke, interactive map of the AOI as a geographic grid. A month control should reveal cumulative activity through that month. Encode the counts of creations, geometry changes, and tag changes separately in each cell and in a monthly timeline. Do not imply that an OSM changeset envelope or returned centroid is an exact work footprint; these are coarse aggregate marks from contribution centroids. Explicitly disclose that deletion records without a centroid are not placed. Keep the map intelligible on desktop and mobile, keyboard-operable, and self-contained after build. Use a dedicated Canvas 2D renderer with no runtime map framework, public OSM tiles, Nominatim, Overpass, or generated imagery.

Attribute OpenStreetMap contributors and ohsome; identify ODbL 1.0 and share-alike obligations. Cite the AOI, year, filter, API route, retrieval date, and extraction/bake steps. Explain that the number of edits is not a count of distinct people or proof of quality. Keep all source identifiers out of the browser bundle and baked payload.

Before implementation, add failing tests for input validation, date inclusion, spatial bin boundaries, deletion-without-geometry handling, event-type aggregation, and cumulative month totals. Bake the bounded real data, inspect output for prohibited identifiers, test coordinate placement and drawing pixels in a browser, benchmark the actual renderer, review the screenshot, then update the example's docs and TODO evidence.
