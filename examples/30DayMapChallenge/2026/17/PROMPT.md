# Day 17 map brief / creation prompt

Create an original, executable map for 30DayMapChallenge 2026 Day 17, **“Light & dark”**, using the locally available MLIT National People Flow Open Data. The map must make the theme legible through a simultaneous comparison of daytime and late-night human-presence estimates: use identical 1 km meshes, a fixed month, dayflag, and geographic window in both panels, with a restrained pale daytime palette and a dark late-night palette. A shared linear scale and a paired legend must make the comparison honest and readable.

This is a map of **average people present**, not a map of observed artificial light, illumination, or satellite night lights. State that directly in the title/subtitle and source note. The source defines daytime as 11:00–14:00 and late night as 01:00–04:00; it averages daily observations over a month and omits counts below 10, so an absent mesh is unknown/suppressed rather than zero. Do not interpolate suppressed meshes or label differences as people moving between places.

Use a real, bounded Tokyo-area mesh extract from the 2021-12 snapshot: prefecture code `13`, all-days `dayflag=2`, daytime `timezone=0` (11:00–14:00) and late night `timezone=1` (01:00–04:00), selecting version `2020` mesh centres in longitude 139.55–139.98°E and latitude 35.53–35.82°N. Source metadata confirms the schema uses string mesh/time identifiers and integer population. The verified window contains 1,016 mesh geometries, 682 daytime records (sum 11,951,622; max 190,197), and 671 late-night records (sum 10,198,442; max 53,824). Recheck these values from the exact baked output. Mesh cell bounds are WGS84. Preserve the source vintage, month, dayflag, timezone definitions, centre-based spatial filter, counts, and exact official attribution in `spec.yaml`, `REQUEST.md`, and `README.md`; credit “全国の人流オープンデータ”（国土交通省） and link its CKAN page. State that the underlying terms follow Government of Japan Standard Terms of Use 2.0 / CC BY 4.0.

Implement a dedicated dependency-free Canvas 2D renderer; do not use a basemap, mapping library, generated image, or fake geography. Draw the two panels with the same extent, dimensions, scale, and mesh footprints, project WGS84 locally with latitude cosine correction, and provide a synchronized crosshair/selection that reports each panel’s available published count without treating missing values as zero. The fixed month and filtering rules must be inspectable in the page. Make the contrast usable on narrow screens and keyboard-accessible. Add TDD coverage for data filtering, mesh pairing, projection, shared scale, unknown/suppressed values, real painted pixels, pointer/keyboard selection, and attribution/disclosure.

Use a bounded, resource-capped bake from the local published Parquet inputs; browser runtime must load only the resulting compact payload and make no external map/data requests. Run the repository’s full tests and type checks under the required resource cap, perform browser checks and visually inspect a screenshot, then record three browser benchmark runs with first-frame, frame, draw CPU, and code/data gzip metrics.
