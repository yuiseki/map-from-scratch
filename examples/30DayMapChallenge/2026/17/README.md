# 30DayMapChallenge 2026 · Day 17: Light & dark

東京都の1 kmメッシュで、2021年12月の昼間と深夜の平均滞在人口推計を左右に比較します。1 kmセル、地理範囲、対数色尺度の上限は両側で共通です。昼は淡い紙色と橙、深夜は濃紺と淡黄で、時間帯ごとの印象を変えています。

この地図が示すのは人流データの昼夜差です。衛星で観測した照明・夜間光ではありません。値はスマートフォンアプリ由来の月平均滞在人口推計で、10人未満の値は公表されません。メッシュに値がない場合は「未公表 / 値なし」と扱い、ゼロに置き換えたり個人の移動を推測したりしません。

## 出典

出典：「全国の人流オープンデータ」（国土交通省）（[データセット](https://www.geospatial.jp/ckan/dataset/mlit-1km-fromto)）を加工して作成。固定スナップショットは2022-01、収録期間は2019-01〜2021-12。東京都、2021年12月、全日、timezone 0（11–14時）と timezone 1（1–4時）を使用しました。地域を絞るときは市区町村別の配分表から同一メッシュ内を合計し、`attribute_mesh1km` の2020年版WGS84境界と結合しました。メッシュ中心が139.55–139.98°E、35.53–35.82°Nの半開区間にあるセルを選びました。

利用条件は「全国の人流オープンデータ利用規約」（令和3年1月27日）に基づく政府標準利用規約2.0相当（CC BY 4.0相当）です。データの詳細と加工記録は [REQUEST.md](./REQUEST.md) と [stats.json](../../../../data/baked/30DayMapChallenge-2026-17/stats.json) にあります。

## 実行・計測

データを再生成するには `bin/mfs bake 30DayMapChallenge-2026-17`、ページをビルドするには `bin/mfs build 30DayMapChallenge-2026-17`、3回の画面計測には `bin/mfs bench 30DayMapChallenge-2026-17 -n 3` を実行します。これらの実データ処理は、リポジトリの資源上限ルールに従って実行してください。

この例は依存ライブラリを使わず、Canvas 2D とネイティブなキーボード・ポインター操作だけで描画します。矢印キーで隣接メッシュへ移動し、Escapeで選択を解除できます。

## 計測

3回のChrome/Xvfb計測は全9 budgets・8 browser checksが通過しました。初回描画 p50 114.585 ms、frame p95 13.145 ms、draw CPU p95 5.955 ms、コード gzip 12,639 B、データ gzip 11,834 Bです。1280×800のスクリーンショットで、左右の地図、共通凡例、出典と注意書きが重ならないことを確認しました。
