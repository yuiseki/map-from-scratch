# Day 22 — Projections

## Request

Let the reader see what a projection does to one world by switching among at
least four mathematically distinct global projections. Keep the countries,
viewport, reference scale and visual treatment consistent. Show a graticule and
equator, name the preserved property or characteristic distortion, and make
Mercator's finite latitude domain explicit.

## Data and implementation

The bake reads Natural Earth `ne_110m_admin_0_countries`, the 1:110m Admin 0
countries layer in the v5.1.2 collection. The layer's own `.VERSION.txt` and
card record version 5.1.1. The checked local source is
`/sata_hdd_24tb/hf_data/__published/natural-earth/data/parquet/v5.1.2/110m_cultural/ne_110m_admin_0_countries.parquet`.
It has 177 features (148 Polygon, 29 MultiPolygon), WGS 84 / EPSG:4326, and is
public domain. The bake keeps all country geometries and coordinates and only
selects the country code and display name in addition to geometry. No source
filtering, geometry repair, CRS conversion, simplification, or scale changes
are made. The exact vertex count and generated byte counts are recorded in
`data/baked/30DayMapChallenge-2026-22/stats.json`.

One baked country geometry array drives every view. Projection math is in the
dedicated `projections.ts`, not a general map or projection library:

- **Equirectangular:** `x = λ`, `y = φ` (radians).
- **Mercator:** `x = λ`, `y = ln(tan(π/4 + φ/2))`, clipped at
  `|φ| = 85.05112878°` to keep a finite square world.
- **Equal Earth:** the published polynomial with constants
  `A1=1.340264`, `A2=-0.081106`, `A3=0.000893`, `A4=0.003796` and
  `θ=asin(√3/2 sin φ)`.
- **Winkel Tripel:** the mean of the Aitoff and equirectangular coordinates,
  with standard parallel `acos(2/π)`.

The fixed radians-to-screen scale and 10° equatorial bar remain the same while
the selector changes. Lines crossing ±180° are split before projection;
invalid latitudes and non-finite projected points are discarded. The
Canvas 2D renderer samples graticules at 3° and does not request runtime data,
fonts, images or tiles from other origins.

## Validation status

`projections.test.ts` covers known origins, symmetry, distinct formula output,
Mercator's clipped and unclipped domain, Equal Earth's finite polar boundary,
antimeridian splitting, and the screen transform. Browser checks exercise
actual canvas pixels, selection, country count, disclosure text and runtime
network. The capped 3-run browser measurement passed all 8 budgets and 6
checks: first frame p50 30.3 ms, draw CPU p95 6.01 ms, frame interval p95
16.31 ms, code gzip 6,825 B, data gzip 177,700 B. The 1280×800 screenshot was
visually reviewed.
