# Day 26 · Water — 荒川の洪水浸水想定

FY2025 国土数値情報 A31a の「想定最大規模」から、荒川（河川管理者: 関東地方整備局）の浸水深ポリゴンだけを表示する専用 Canvas 2D 描画器です。図形は東経 139.79–139.85 度、北緯 35.70–35.76 度の矩形でクリップしています。この矩形は表示範囲であり、行政区域ではありません。

## 出典データ

- [国土数値情報 洪水浸水想定区域データ（河川単位）A31a FY2025](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A31a-2025.html)
- [データカードとライセンス](https://huggingface.co/datasets/yuiseki/ksj-a31a-flood-tokyo23)
- 出典 CRS: JGD2011 地理座標系 EPSG:6668。描画時に中心を原点とするローカル正距円筒近似へ変換します。
- 対象属性: 想定最大規模 `A31a_201`–`A31a_205`。河川名 `A31a_202`、河川管理者 `A31a_204`、浸水深ランク `A31a_205`。
- 元ファイル: bbox付き空間順序付き `A31a-25_83_10_GEOJSON-part0.parquet` と `part1.parquet`。この範囲で交差した出典 `source_file` は `data/baked/30DayMapChallenge-2026-26/stats.json` に記録します。
- この範囲のベイク結果: 2,264ポリゴン、124,919頂点、深さランク別の地物数 1:163 / 2:423 / 3:757 / 4:919 / 5:2 / 6:0。feature bbox と点検用代表点を含むJSON 4,177,970 byte。
- ライセンス: CC BY 4.0、国土数値情報利用規約に従います。出典表示はページ下部にあります。

## 表示上の注意

これは河川管理者が提供した浸水想定に基づくモデル区域で、実際の洪水記録・予報・リアルタイム警報ではありません。住所単位の安全保証、個人のリスク評価、全河川や内水氾濫の網羅を示しません。元資料は位置精度や実際の状況との差に関する注意を示しています。

ドラッグで移動、ホイールまたはボタンで拡大縮小、ポリゴンのクリックで元の河川・管理者・カテゴリ・深さランクを確認できます。右下に座標と範囲、画面内に 500 m のスケールバーがあります。

## 開発

```sh
bin/mfs bake 30DayMapChallenge-2026-26
bin/mfs bench 30DayMapChallenge-2026-26 -n 3
```

ベイクはローカル元データを読みます。すべてのデータ読み込み、テスト、型検査、ベンチはリポジトリの資源上限を付けて実行してください。

## 計測

2026-11-05 の資源上限付き Chrome 156 / 1280×800 3反復計測では、2,264ポリゴン・124,919頂点から初回描画p50 213.5 ms、frame p95 4.48 ms（最大10.51 ms）、描画CPU p95 0.205 ms（最大1.27 ms）でした。コードgzip 9,678 byte、データgzip 534,524 byte、外部originリクエスト0件で、3反復すべての予算とブラウザ検査に合格しました。これは表示Canvasのピクセルを直接読んでいたベンチの結果で、修正後の再測定待ちです。ブラウザの実ピクセルから計測した浸水色の合計は391,402 pxです。
