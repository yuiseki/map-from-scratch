# Day 29 — Raster

ETOPO の数値標高ラスターを、地図タイルや画像への変換を介さずに読んで描く。公式 NOAA NCEI の 30 arc-second グローバル bedrock GeoTIFF から、東京・富士山・日本海溝を含む中央本州から西太平洋の初期範囲 `[138.5, 34.5, 144.5, 40.5]` に必要な TIFF ブロックだけを HTTP Range で取得する。Float32 標高を WebGL2 の R32F テクスチャに渡し、フラグメントシェーダーで海底・海面・陸地を塗り分ける。地図上を移動・拡大縮小し、元ピクセルの標高を調べる。

## 完了条件

- classic TIFF の必要メタデータとブロック索引だけを読み、固定 AOI と交差するブロックを選ぶ。
- 各応答の 206 / Content-Range / Content-Length を検証する。予期しない 200 は body を読み切らずキャンセルし、最大1回だけ再試行する。
- DEFLATE と TIFF Predictor=3 をブラウザー標準 API で復号し、元の Float32 値を保持する。
- WebGL2 専用描画器で海底の負値、海面、陸地の正値、NoData を表現する。
- 任意地点を選んで座標と標高を表示し、出典と航海用途ではない注意を示す。
- ダウンロード全体を取得せず、生成画像や事前タイルに依存しない。
