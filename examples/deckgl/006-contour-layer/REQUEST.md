# deck.gl ContourLayer に対応する専用描画器

## 依頼

> 米国の郡別COVID-19新規感染者数を人口10万人当たりに直し、週と集計セルの大きさを変えながら等値帯・等値線で見たい。

[元例](https://deck.gl/examples/contour-layer)と同じ [3,214郡の週別データ](https://github.com/visgl/deck.gl-data/tree/master/examples/contour)を使う。元データは [The New York Times のCOVID-19データ](https://github.com/nytimes/covid-19-data)に由来し、NYTのライセンスは**非商用利用と公開時の帰属表示**を条件としている。配布するデータもこの条件で扱う。

## 設計

- 週0〜86の人口10万人当たり新規感染者数を、対数12ビット量子化で1郡140バイトに格納する。元値の最大は11,520.7件/10万人で、12,000まで表現できる。
- 集計セル内の郡の値の最大を採る。週・セル寸法の変更時だけ値グリッドを更新し、`R32F` テクスチャへ転送する。セル寸法は緯度40度でのWeb Mercator距離へ換算する近似で、元例のメートル単位グリッドと完全一致しない。
- ナビゲーション中は全画面三角形1枚のフラグメントで値を補間し、6段階の等値帯または等値線を描く。Natural Earth 110m陸地を背景にする。道路・地名ラベルは含めない。
- 元の deck.gl 版との同条件比較は今後実施する。比較が完了するまで速度の優劣は主張しない。

## 計測

`bin/mfs bench deckgl-006-contour-layer --site` を3回反復した。GPUは NVIDIA GeForce RTX 3060（Vulkan）、画面は1280×800・DPR 1。3,214郡・87週のデータとNatural Earth 110m陸地を配信した。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回描画 p50 | 99.09 ms | 1000 ms 以下 |
| パン・ズーム中のフレーム p95 | 1.21 ms | 8.3 ms 以下 |
| パン・ズーム中の CPU p95 | 0.09 ms | 参考値 |
| パン・ズーム中の GPU p95 | 0.02458 ms | 参考値 |
| 週変更とGPU転送 p95 | 2.355 ms | 100 ms 以下 |
| セル寸法変更とGPU転送 p95 | 4.445 ms | 100 ms 以下 |
| コード gzip | 6,192 B | 14,000 B 以下 |
| データ gzip | 423,700 B | 500,000 B 以下 |

全郡の割当、等値帯の表示、等値線への切替、週・セル寸法による画面変化が3反復すべてで通った。公開用ビルドのスクリーンショットも確認した。データ gzip は16ビット版の511,300 Bから12ビット版の423,700 Bへ減った。元の deck.gl 版との同条件比較はまだ行っていないため、速度の優劣は主張しない。
