# deck.gl TerrainLayer に対応する地形描画器（作業中）

[元例](https://deck.gl/examples/terrain-layer)は [Mapterhorn の512px Terrarium標高タイル](https://mapterhorn.com/data-access/)と [VersaTiles の衛星画像](https://versatiles.org/sources/)で地形を描き、場所・地表画像・ワイヤーフレーム・Globe View・タイルのズーム範囲を切り替えられます。この版は元例のセントヘレンズ山の初期地点と画角を採用し、同じ z/x/y の標高と衛星画像を重ねます。主要7地点、衛星画像と標高色、ワイヤーフレーム、移動・回転・拡大縮小を実装しました。ズーム帯を跨ぐ間の親タイル表示、Globe View、Street 地表、最小・最大の各ズーム設定は未実装なので、[TODO](../../../TODO.md) は完了にしていません。

標高は頂点シェーダーで Terrarium から復元します。全タイルが64×64セルのメッシュを共有し、タイルごとに標高と地表画像の2テクスチャを入れ替えます。タイル境界の隙間は600mのスカートで覆います。初期画角は中心から5×5枚のタイルを対象にし、最初の9枚が揃った時点と全25枚が揃った時点を別々に測ります。表示データは元の配信元から直接取得し、再配布しません。

## 計測

`bin/mfs bench deckgl-019-terrain-layer --site`、1280×800・DPR 1、NVIDIA GeForce RTX 3060（Vulkan）、3反復。初期画角はセントヘレンズ山、z12、標高・衛星画像それぞれ25枚です。スクリーンショットで全域の描画を確認し、標高表示・ワイヤーフレーム・地表切替の画面チェックが通りました。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初期9枚の表示 p50 | 833 ms | 10,000 ms 以下 |
| 全25枚の完成 p50 | 1,310 ms | 10,000 ms 以下 |
| カメラ操作のフレーム p95 | 1.545 ms | 16.7 ms 以下 |
| 固定画面のフレーム p95 | 1.440 ms | 16.7 ms 以下 |
| GPU p95 | 0.998 ms | 参考値 |
| コード gzip | 6,888 B | 30,000 B 以下 |
| 転送量 p50 | 3,745 KiB | 参考値 |

同時取得8件では全域完成 p50 4.04秒、16件では2.20秒、25件では1.31〜1.34秒でした。通信先のキャッシュや混雑なども変わりうるため、この差を同時取得数だけの効果とは断定しません。元例の deck.gl 実装を同条件で計測していないため、速度の優劣も未判定です。
