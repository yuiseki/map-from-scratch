# leaflet-001-quick-start: クイックスタートガイドの図形とポップアップ

## 依頼内容

> ロンドン中心部（51.505, -0.09）の地図に、マーカー（ピン）、半径500mの円、三角形のポリゴンを描き、それぞれクリックでポップアップを表示したい。地図上をクリックしたときその地点の緯度経度を出したい。外部ライブラリは使わず軽量に。

元例: [Leaflet - Quick Start Guide](https://leafletjs.com/examples/quick-start/)

## 設計の意図と判断

1. **Canvas 2D による完全同期描画**
   - Leaflet は DOM 要素としてマーカーやポップアップを生成し、CSS `transform` で地図タイルの上に配置しますが、高速なドラッグやホイール拡縮時に DOM レンダリングの再配置遅延（レイアウトスラッシング）が発生しがちです。
   - 本実装ではすべての図形（マーカー、半透明円、ポリゴン）およびポップアップの吹き出しを Canvas 2D 内で直接描画するため、パン・ズーム操作時にもアノテーションがピクセル単位で完全に同期します。
2. **分析的ヒットテスト（Analytic Hit-testing）**
   - 重い空間インデックスライブラリ（rbush 等）を導入せず、マーカーはユークリッド距離、円は半径距離、ポリゴンはレイキャスティング法によるクロス積内外判定を用いて、0.01 ms 未満で即座にクリック判定を行います。
3. **外部依存ゼロ・即時起動**
   - Leaflet 本体（約 40 KB gzip）と CSS を一切使わず、約 3 KB gzip のコードだけで元例の全機能（図形表示、ポップアップ切り替え、地図クリック時の座標表示、パン・ズーム）を提供します。

## 計測と検証

- **初回描画時間**: 陸地データの取得から全アノテーションの初回フレーム完了まで、数ミリ秒で完了します。
- **機能検証**:
  - `marker-visible`: ロンドンのマーカー位置に Leaflet 青（#2A81CB）のピクセルが正しく描画されていることを確認。
  - `circle-visible`: 500m 半透明円（赤 #ff0033）のピクセルが描画されていることを確認。
  - `click-circle-shows-popup`: 円内クリックで "I am a circle." が activePopup に設定されることを確認。
  - `click-polygon-shows-popup`: 三角形ポリゴン内クリックで "I am a polygon." が表示されることを確認。
  - `click-marker-shows-popup`: マーカークリックで "Hello world! I am a popup." が表示されることを確認。
