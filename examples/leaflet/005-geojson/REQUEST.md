# Leaflet GeoJSON チュートリアルに対応する専用描画器

[Leaflet - Using GeoJSON with Leaflet](https://leafletjs.com/examples/geojson/) は、GeoJSON の FeatureCollection を `L.geoJSON` で読み込み、ポイント・ライン・ポリゴンをそれぞれのスタイルで描き、地物をクリックするとプロパティをポップアップに出す例です。

この実装は同じ意図を、`L.geoJSON` のレイヤー生成も DOM 要素も使わずに実現します。ベイク済みの陸地と FeatureCollection を読み込み、投影済みの画面座標へ Canvas 2D のパスで直接描きます。クリック判定はポイント（距離）→ ライン（線分距離）→ ポリゴン（レイキャスティング）の順に行い、当たった地物の `properties.name` を Canvas 上の吹き出しに出します。

地物は、元チュートリアルの例示データと同じ位置づけです。5つの実在都市（ロンドン、パリ、ベルリン、マドリード、ローマ）のポイント、ロンドン-パリ-ベルリンを結ぶ例示ルート、中央ヨーロッパの矩形ポリゴンを1つの FeatureCollection にしています。ルートは実際の交通路ではありません。

元例との同条件の速度・画面比較は未実施です。元例は DOM ベースの SVG レイヤーなので、フレーム時間をそのまま比較できません。

## データと帰属

- 背景の陸地: Natural Earth 110m land（パブリックドメイン）。
- 地物: この例のために用意した例示データ（実在都市の座標のみ実データ）。

## 計測

`bin/mfs bench leaflet-005-geojson -n 3` を3反復した。画面は1280×800・DPR 1。Canvas 2D なので GPU 時間は取得できない（`gpu: n/a`）。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 10.1 ms | 300 ms 以下 |
| 再描画 p95 | 0.67 ms | 2.0 ms 以下 |
| フレーム間隔 p95 | 5.85 ms | 20 ms 以下 |
| コード gzip | 3,595 B | 6,000 B 以下 |
| データ gzip | 30,680 B | 40,000 B 以下 |

画面ピクセルとポップアップの検証6項目は3反復すべてで通った。

## 実装のメモ

- ポップアップは DOM ではなく Canvas に描くので、パン・ズームと 1 フレームもずれない。
- クリック判定は地物数が少ない前提で、空間インデックスを使わない。
- 検証は画面ピクセルの読み戻しと `activePopup` の内容で行う。
