# D3 world map に対応する専用描画器

[D3 の world map](https://observablehq.com/@d3/world-map) は、Natural Earth の 110m 陸地と 10 度刻みの経緯線を正距円筒図法（equirectangular）で SVG に描く静的な図です。この実装は同じ陸地データをベイク時に [0, 1] の正距円筒座標へ投影し、Canvas 2D で塗ります。

元例は SVG のパスを DOM に置き、D3 本体と world-atlas の TopoJSON を読み込みます。この実装は配布するコードを TypeScript の型ストリップ済みモジュールだけにし、実行時の外部依存を持ちません。

日付変更線をまたぐリング（アラスカ、チュクチ半島、南極大陸など）は、ベイク時に ±180 度で分割してから [0, 1] へ正規化しています。分割しないと、リングが地図全体を横切る帯になって塗られます。元例の d3-geo も同じ位置でジオメトリを切ります。

元例との同条件の速度・画面比較は未実施です。元例は SVG で、この実装は Canvas 2D のため、フレーム時間をそのまま比べられません。

## データと帰属

- Natural Earth 110m land（パブリックドメイン）。元例と同じ Natural Earth 系の陸地データです。

## 計測

`bin/mfs bench d3-005-world-map -n 3` を3反復した。画面は1280×800・DPR 1。Canvas 2D なので GPU 時間は取得できない（`gpu: n/a`）。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 8.87 ms | 300 ms 以下 |
| 再描画 p95 | 0.485 ms | 8.3 ms 以下 |
| フレーム間隔 p95 | 9.845 ms | 20 ms 以下 |
| コード gzip | 1,896 B | 4,000 B 以下 |
| データ gzip | 30,610 B | 40,000 B 以下 |

画面ピクセルの検証4項目（陸地と海、日付変更線の両側、経緯線、再描画の安定性）は3反復すべてで通った。

## 実装のメモ

- 経緯線を陸地より先に描くので、線は海の上だけに見える。
- リサイズ時は全体を描き直す。パン・ズームは持たない（元例と同じ静的表示）。
- 検証は画面ピクセルの読み戻しで行う（陸地・海・日付変更線・経緯線・再描画の安定性）。
