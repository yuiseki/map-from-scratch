# D3 "Solar terminator" に対応する専用描画器

[Solar terminator](https://observablehq.com/@d3/solar-terminator) は、世界地図の上に太陽直下点と昼夜の境界（明暗境界線、terminator）を描き、時刻を動かすと夜の範囲が地図の上を動く例です。

この実装は同じ景色を外部ライブラリなしの Canvas 2D で描きます。日付は 2026-10-30 に固定し、太陽直下点は NOAA の近似式（赤緯と均時差）から時刻だけの関数として実行時に求めます。夜は投影した円ではなく、画面の行ごとに「夜になる経度の幅」を `acos(tan(lat)·tan(dec))` で求めて塗るので、極の閉じ方も 180 度線の分割も要りません。スライダーで UTC 時刻を動かすと夜の範囲と直下点が動き、再生ボタンで日周運動が回ります。ドラッグで移動、ホイールで拡大・縮小できます。

元例との同条件の速度・画面比較は未実施です。元例は d3-geo の正射図法と SVG、この実装は Web Mercator の Canvas 2D です。

## データと帰属

- 背景の陸地: Natural Earth 110m land（パブリックドメイン）。ベイク時に Web Mercator 座標へ投影。
- 太陽位置: NOAA の近似式。日付は 2026-10-30 固定。

## 計測

`bin/mfs bench d3-019-solar-terminator -n 3` を3反復した。画面は1024×768・DPR 1。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 17.6 ms | 300 ms 以下 |
| 再描画 p95（時刻を動かす60フレーム） | 1.43 ms | 2.0 ms 以下 |
| フレーム間隔 p95 | 8.22 ms | 20 ms 以下 |
| コード gzip | 4,385 B | 5,500 B 以下 |
| データ gzip | 30,400 B | 40,000 B 以下 |

画面ピクセルと操作の検証10項目は3反復すべてで通った。

## 実装のメモ

- 夜は緯度ごとの経度区間で描く。太陽高度の余弦が `sin(lat)sin(dec) + cos(lat)cos(dec)cos(H) > 0` のとき昼なので、夜は反対点の経度を中心に半幅 `acos(tan(lat)tan(dec))` の帯になる。緯度が極夜側なら行全体、白夜側なら描かない。768 行の矩形を1パスにまとめる。
- 太陽直下点は日付と時刻だけで決まるのでベイクしない。2026-10-30 12:00 UTC で緯度 -13.5 度・経度 -4.1 度、反対点が夜、北緯 80 度が夜、南緯 80 度が昼になり、検証項目で確かめている。
- 初版は夜の半幅を `acos(-k)` としていたため、高緯度で昼夜が反転していた（北緯 76 度の帯だけが夜になっていた）。画面を見て気づき、`acos(k)` に直し、北緯 76 度の正午の 90 度西が夜である検証項目を足した。点ごとの検証は反転を通してしまっていた。
