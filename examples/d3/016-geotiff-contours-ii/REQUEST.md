# D3 GeoTIFF contours に対応する専用描画器

[元例](https://observablehq.com/@d3/geotiff-contours-ii)と同じ 720×361 の GeoTIFF 添付ファイルを使い、世界の地表気温を Natural Earth 投影の等値帯で示します。GeoTIFF の GRIB メタデータは、2016年7月26日を基準とする8月2日の地表気温予報を示しています。ファイルの値域は -72.65〜68.35 で、温度単位の記載は K ですが、数値は摂氏に換算されたように見えます。この食い違いがあるため、画面では温度の解釈に注意が必要です。

元の Notebook は等値線のポリゴンを D3 で計算してから投影します。この実装は同じ格子を16ビットでGPUに送り、Natural Earth の逆投影と等値帯の判定を WebGL2 のフラグメントシェーダーで行います。格子間は最近傍で参照するため、元例の補間された境界形状と一致しません。元例との同条件の速度・画面比較は未実施です。

元の添付ファイルの作成者・再配布条件は Notebook に明示されていません。GRIB メタデータは NOAA GFS 形式と整合しますが、作成経路は未確認です。公開ページは [D3 Notebook](https://observablehq.com/@d3/geotiff-contours-ii) をデータ出典として明示し、数値の変換を記載します。NOAAのデータ一般については[公式FAQ](https://www.noaa.gov/office-education/outreach-communication/faq)が原則としてパブリックドメインと説明していますが、この添付ファイルへの適用は断定しません。

## 計測

`bin/mfs bench d3-016-geotiff-contours-ii --site` を3反復した。画面は1280×800・DPR 1、GPUは NVIDIA GeForce RTX 3060（Vulkan）。公開用ビルドのスクリーンショットを確認した。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 51.48 ms | 1000 ms 以下 |
| 間隔変更中のフレーム p95 | 1.31 ms | 8.3 ms 以下 |
| 固定画面のフレーム p95 | 0.26 ms | 8.3 ms 以下 |
| GPU p95 | 0.05837 ms | 参考値 |
| コード gzip | 3,771 B | 12,000 B 以下 |
| データ gzip | 237,400 B | 600,000 B 以下 |

全格子点の読み込み、地球全体の表示、等値帯間隔による画面変化が3反復すべてで通った。元の D3 版との同条件比較は未実施のため、速度の優劣は判定していない。
