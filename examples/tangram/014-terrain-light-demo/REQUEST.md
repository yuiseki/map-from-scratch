# tangram-014-terrain-light-demo

マウスで動かす光で地形を照らし、尾根と谷を浮かび上がらせたい。本物の地形 (Mapterhorn) で富士山と富士五湖を、
標高で持ち上げた 3D の地形として斜めから眺め、ドラッグで回し、ホイールで寄る。光はマウスに従い、トグルで太陽が一日かけて空を渡る。
ランバート拡散、湖の鏡面反射、低い太陽で山が谷に落とす影も出す。

## 元の例

- Tangram: [terrain-light-demo](https://github.com/tangrams/terrain-light-demo) (MIT)。Leaflet の 2D 地図に Mapzen の法線タイル
  (`terrain/v1/256/normal`、サービス終了) を貼り、平行光 (シアン) と点光源 (赤) を dat.GUI で動かす。`mouse control` を入れると
  平行光の方向の x, y がポインターの画面上の位置 (-1..1) になる。`DEMO MODE` は時刻の sin で方向と色を回す。`terrain scale` で法線の z を割る。
- 元の例ではポインターの位置が光の進む向きなので、光はポインターの反対側から当たる。ここでは「ポインターの側に光がある」とした
  (方位 = 画面中心のまわりのポインターの角度 + カメラの方位、高度 = 中心で 90°、短辺の半分で 1°)。
- 元の例の再現: 光の追従、DEMO MODE (太陽ボタン、色も低い太陽で赤くなる)、terrain scale (高さの倍率スライダー)。
  点光源と色の GUI は入れていない。

## 設計

- データ: Mapterhorn z11 (31.14 m) の 1280x1024 テクセル、138.51-138.95E 35.29-35.57N (39.9 x 31.9 km)。
  0.25 m に量子化し、平面予測の int16 残差。湖は OSM (natural=water と landuse=reservoir) をテクセルの格子に焼いたマスク。
  gzip 1,233,826 B の 1 ファイル。ページは DecompressionStream で展開する。
- 法線: 焼かない。読み込み時に中央差分の勾配を RGBA16F テクスチャにし (b に水のマスク)、フラグメントで高さの倍率をかけて法線にする。
  メッシュは 2 テクセルおき (641x513 頂点、頂点バッファーなしで gl_VertexID から作る) だが、陰影は 1 テクセルの細かさで出る。
- 影: 高さ場のテクセル空間で、光の方へ 1 テクセルから対角までの等比 96 歩を進み、最も急な見上げ角と太陽の高度を比べて R8 に書く。
  光か倍率が変わったときだけ作り直す。区画の外の地形は無いので、影は区画の端で途切れる。
- 光: ランバート + 空の環境光 (法線の z で変える) + 水だけの Blinn-Phong (指数 120)。sRGB へのガンマ 2.2。

## 学んだこと

- 湖の多角形の頂点の平均は湖の外に落ちる (精進湖、河口湖)。検査点は ST_PointOnSurface で取る。
- 量子化 0.1 / 0.25 / 0.5 / 1 m で gzip 後の高さは 1.49 / 1.23 / 1.02 / 0.82 MB。低い太陽の段を嫌って 0.25 m。
- 範囲を覆う原本の WebP タイル 12 枚は 4,989,416 B。
