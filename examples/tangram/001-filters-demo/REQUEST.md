# Tangram "Filtering data" (filters-demo) に対応する専用描画器

[filters-demo](https://github.com/tangrams/filters-demo) は、Tangram のスタイルで地物を属性によって絞り込み、表示する道路の種別を切り替えるデモです。

この実装はサンフランシスコ湾岸の道路 721 セグメント（州道 SR 589・US 国道 29・州間高速 I 103）をベイク時に種別ごとのグループへ分け、Canvas 2D で種別ごとに 1 本のパスへまとめて描きます。チェックボックスで種別の表示を切り替えられ、切り替えは再描画 1 回で反映されます。ドラッグパンとホイールズームを持ちます。

元例との同条件の速度・画面比較は未実施です。元例は WebGL、この実装は Canvas 2D です。

## データと帰属

- 背景の陸地: Natural Earth 110m land（パブリックドメイン）。
- 道路: deck.gl-data の US highway roads（MIT リポジトリ、元データの出典表記に従う）からベイエリアを切り出し。

## 計測

`bin/mfs bench tangram-001-filters-demo -n 3` を3反復した。画面は1024×768・DPR 1。Canvas 2D なので GPU 時間は取得できない（`gpu: n/a`）。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 26.7 ms | 300 ms 以下 |
| 再描画 p95 | 1.15 ms | 2.0 ms 以下 |
| フレーム間隔 p95 | 10.21 ms | 20 ms 以下 |
| コード gzip | 2,903 B | 4,500 B 以下 |
| データ gzip | 40,400 B | 200,000 B 以下 |

画面ピクセルの検証6項目は3反復すべてで通った。

## 実装のメモ

- 種別フィルタは描画時のグループ単位の有無で切り替える。フィーチャごとの判定ループは持たない。
- 検証用プローブはベイク時に「他種別から最も遠い頂点」として選び、非表示前後の色判定を安定させる。
