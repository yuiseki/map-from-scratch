# tangram-004-highways-demo

Mapzen Tangram の「highways-demo」のように、ズームレベルに応じて高速道路（ハイウェイ）の線幅やグロー効果が滑らかに変化するズーム連動道路スタイリング（Zoom-dependent road styling）をダークテーマ地図上で表示したい。ドラッグでパン、ホイールで拡大縮小できること。外部ライブラリなし、Canvas 2D で最速・最小で実装する。

## 元の例
- Tangram: [Zoom-dependent road styling](https://github.com/tangrams/highways-demo)
