# 地球全体の標高を 3D で見る

全球の z0～12 は [Mapterhorn の単一タイル HTTP エンドポイント](https://mapterhorn.com/data-access/)から WebP 標高タイルを取得します。z13 以上は [download_urls.json](https://download.mapterhorn.com/download_urls.json) にある地域別アーカイブの緯度経度範囲とズーム範囲を調べ、表示するタイルを含む PMTiles の索引とタイルを HTTP Range で読みます。全球を表示してから、富士山、アルプス、ヒマラヤ、グランドキャニオンなどに近づけます。

専用の WebGL2 描画器が Web Mercator の標高タイルを球面上の三角形へ変換します。WebP の RGB 値を Terrarium 形式の標高へ復元し、メッシュの高さと陰影に使います。表示範囲と高度に応じて z0～18 のタイルを選び、細かいタイルが届くまで、またはその地域に存在しない場合は、読み込み済みの親タイルで描きます。地域別アーカイブの最大ズームは場所により異なります。カメラの高度は注視点の標高を基準にするため、山の上でも近づけます。標高の色は描画器で付けています。Mapterhorn には海底地形がなく海は標高 0 m ちょうどなので、0 m 以下を海の色にしています。標高タイル以外の背景地図、MapLibre、地形プラグインは使いません。

ドラッグで地球を移動し、ホイールまたはボタンで拡大縮小します。右ドラッグまたは Shift＋ドラッグでカメラの傾きを変えられます。高さの強調率はスライダーで調整できます。画面には読み込んだ区画、CDN タイルの取得量と地域別 PMTiles の Range 通信量を示します。全球の表示では地域別アーカイブの一覧を待たずにタイル取得を始めます。地域別アーカイブの表示では、先に必要な詳細タイルと一枚の粗い親タイルを取得します。

元データは [Mapterhorn](https://mapterhorn.com/attribution/) です。日本の範囲には国土地理院の基盤地図情報（数値標高モデル）を含むデータが使用されています。地球儀は Web Mercator の範囲（緯度約 ±85°）を描き、メッシュは標高タイルの画素より粗い 64×64 分割です。性能計測と操作の自動検証は未実施です。
