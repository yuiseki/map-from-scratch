# forge3d-005-3d-buildings

オランダの 3D 建物データ (3DBAG の CityJSON タイル 1 枚、デン・ハーグ中心部の 277 棟) を三角形のメッシュにして立体で見る。地面に 100 m の格子を引き、ドラッグで回り、ホイールで寄れる。建物をクリックすると、BAG の番号、建築年、高さ、屋根の形、体積を出す。外部ライブラリなし。

## 元の例

- forge3d: [3D Buildings](https://milos-agathon.github.io/forge3d/gallery/05-3d-buildings.html)
- 元の例は `add_buildings_cityjson()` で CityJSON のタイル `10-270-592.city.json` を三角形のメッシュに分け、そのメッシュを直接プレビューする (forge3d では有償機能)。画像は格子付きの地面に茶色の建物が並ぶ斜め上からの 1 枚。

## 設計

1. 三角形分割はベイクで済ませる。
   - 279 の BuildingPart の LoD 2.2 の立体を、面ごとに Newell の法線で主な平面を選んで投影し、earcut で三角形に分ける。穴のある面は 119。
   - 面積 0 の 10 面は earcut が何も返さないので落ちる。
2. 頂点は CityJSON の頂点と建物の組ごとに 1 つ。
   - 面ごとに作ると 124,146 頂点 (1,870 KB) だったが、同じ建物の面どうしで角を共有すると 38,962 頂点になり、16 bit のインデックスに収まった (755 KB、gzip 471 KB)。
   - 隣の建物とは頂点を共有しない。頂点が持つ建物の番号でクリックを当てるため。
3. 頂点は 8 バイト。位置を 16 bit に量子化した 3 つ (約 9 mm) と建物の番号。
   - 法線は持たない。フラグメントシェーダが世界座標の `dFdx` と `dFdy` の外積から面の法線を取り、その向きで屋根 (上向き) と壁を色分けし、北西の太陽で明るさを掛ける。
4. 描画は地面と建物の 2 回。建物は 76,824 三角形を 1 ドローコール。地面の 100 m の格子はシェーダで引き、`fwidth` でどの距離でも 1 画素幅にする。
5. クリックしたときだけ、画面外のフレームバッファに建物の番号を色として描き、クリックした 1 画素を読む。選ばれた建物は橙で描き直す。
6. CityJSON は RD New (EPSG:28992) と NAP の高さのまま、タイルの中心を原点にして使う。地面はクリックで出す地面の高さ (b3_h_maaiveld) の中央値に置く。

## 計測結果

`bin/mfs bench forge3d-005-3d-buildings -n 3` (1024x768、DPR 1、ANGLE / NVIDIA RTX 3060)。

| 項目 | 値 | 予算 |
| --- | --- | --- |
| 初回描画 first_frame_ms p50 | 33.9 ms | 500 ms |
| 再描画 redraw_ms p95 | 0.045 ms | 8 ms |
| フレーム間隔 frame_interval_ms p95 | 0.33 ms | 20 ms |
| クリックの判定 pick_ms p95 | 1.37 ms | 16 ms |
| コード gzip | 6,286 B | 8,000 B |
| データ gzip | 530,800 B | 560,000 B |
| 検証チェック | 5 / 5 PASS (3 回とも) | |

redraw_ms は CPU が描画命令を出し終えるまで、frame_interval_ms は vsync なしの rAF の間隔で、どちらも GPU の実行時間は含まない。pick_ms は画面外の描画と 1 画素の読み戻しで、GPU を待つので GPU の時間を含む。

データの予算は最初 520,000 B にしていたが、自分で gzip して見積もった値 (471 KB) とハーネスの値 (530.8 KB) が違ったので、560,000 B に上げた。

## 検証チェック

- `pick-finds-the-building`: 真上から、体積の大きい 5 棟それぞれの最も高い頂点を投影して当てると、5 棟とも自分を当てる。地面の外の隅は 0。
- `click-selects-a-building`: 最大の建物の最高点に pointerdown と pointerup を送ると、その建物が選ばれ、パネルに BAG の番号と建築年が出て、画素の青と赤の比が屋根の色からハイライトの橙に変わる。最初は「R > 200」で判定して落ちた。ハイライトの色にも陰影が掛かるので、明るさによらない比で見るよう直した。
- `buildings-stand-up`: 最も高い頂点を持つ建物の最高点とその真下の地面を仰角 12° から投影すると、20 px より高く描かれる。
- `roof-colour-from-above`: 真上から見た最も高い屋根の画素が屋根の色 (R - B > 40)。
- `orbit-and-zoom`: 方位を 45° 回すと最大の建物が動き、半径を半分にすると 5 棟の広がりが 1.6 倍より大きくなる。

## 元の例との違い

- 元の例は静止画 1 枚。ここでは回したり寄ったりでき、クリックで属性を出す。
- 元の例の画像にある地面の影は描いていない。
- 汎用ライブラリや forge3d 本体とは、同じ条件で並べて測っていない。
