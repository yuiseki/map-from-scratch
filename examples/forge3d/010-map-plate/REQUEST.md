# forge3d-010-map-plate

forge3d のギャラリー例「Map plate」のように、3D 標高データ（マウント・レーニア周辺の Mini DEM、Bounding Box [-122.0, 46.7, -121.6, 46.95]）から生成された陰影段彩レリーフを、地図枠（二重ニートライン）、方位記号（North Arrow）、スケールバー（Scale Bar）、標高凡例（Legend）、タイトルカルトゥーシュ（Title Banner）といった地図製図要素（Cartographic furniture）と一体化した完成レイアウト（Map Plate）として描画したい。外部ライブラリなし、Canvas 2D で最速・最小で実装する。
