# forge3d-001-mount-rainier

forge3d の代表例「Mount Rainier」のように、Mt. Rainier の DEM を 3D 地形として表示し、ドラッグでオービット、ホイールでズームして山体を眺めたい。太陽は西北 302°・高度 24°に固定。外部ライブラリなし、WebGL2 の 1 ドローコールで最速・最小に実装する。

## 元の例

- forge3d: [Mount Rainier](https://milos-agathon.github.io/forge3d/gallery/01-mount-rainier.html)

## 設計の意図と判断

1. **陰影はベイク時に焼く**
   - 太陽が固定なので、Lambert 陰影と標高段彩（ハイプソメトリック）を 384×384 の RGB テクスチャに焼き込む。実行時のフラグメントシェーダは法線も太陽も持たず、色を引いて大気遠近を混ぜるだけ。
   - 残る実行時の仕事は高さ 1 回の参照と 29 万三角形の描画だけになる。
2. **高さは R16UI テクスチャ、頂点は `gl_VertexID`**
   - 16 bit の標高グリッドを R16UI テクスチャにし、頂点シェーダが `texelFetch` で変位させる。頂点バッファ（384×384×12 バイト）は送らない。
   - 頂点属性はゼロで、`gl_VertexID` から (u, v) を作る。インデックスは 32 bit（65,536 頂点超）の 1 本。
3. **空はキャンバスの CSS グラデーション**
   - WebGL のキャンバスを透明にし、背後の `#map` の CSS グラデーションを空にする。空のシェーダもフルスクリーン三角形も要らない。
4. **カメラは山頂を中心にしたオービット**
   - 注視点は山頂（ベイク時に標高最大のテクセルをヘッダに書く）。方位・仰角・半径から視点を作り、地形の高さ関数で「地表 + 120 m」を下限にして地面へ潜らないようにする（`animation-and-camera` のカメラ高さ制約）。
5. **切り出しは z11 の 2×2 タイル**
   - terrarium z11 の x330-331 / y721-722 を 512×512 に接続し、標高最大点を中心に 384×384（約 20 km、52.3 m/px）を切り出す。範囲は 636〜4,388 m。
6. **検証は画面のピクセルを読む**
   - WebGL では合成後に既定でバッファが消えるため、`preserveDrawingBuffer: true` とチェック前の明示的な `draw()` を入れた（これが無いと全ピクセルが rgba(0,0,0,0) になる）。透明キャンバスなので、空は alpha 0、地形は alpha 255 で区別できる。

## 開発中に踏んだ落とし穴

- 最初の切り出しは TILE_Y=728 を使い、緯度 45.89〜46.07 度（標高 636〜1,792 m）で山頂が入らなかった。z11 の行番号を 721 に直して初めてレーニア山頂が入った。
- オービットの検証で「山頂の画面 x」を測ると、山頂は回転中心なので常に画面中央から動かず FAIL した。2 km 東の点を投影するよう変えている。
- 谷の検証では候補点が画面外に投影されることがあり、画面内の候補だけを比較対象にした。

## 検証チェック

- `terrain-fills-view`: 空 (20, 20) の alpha < 10、画面中央 62% 高さの alpha > 200。
- `summit-is-snow`: 山頂テクセル（u=0.546, v=0.374）の alpha > 200、輝度 > 90、RGB 最大差 < 30（雪は無彩色で明るい）。
- `summit-stands-above-valley`: 山頂から 1.2〜4 km のカメラ方向で最も低い DEM サンプルが画面内に投影され、山頂より 6 px 以上下に描かれる。
- `orbit-moves-terrain`: 山頂から 2 km 東の点を投影し、az を 60°回した前後で画面 x が 40 px 以上動く。中央の地形 alpha > 200。
- `zoom-changes-scale`: 山頂と 1.5 km 東の点の画面距離が、半径 9 km と 5 km で比 > 1.5。

## 補足

- 結果ファイル（`results/forge3d-001-mount-rainier/latest.json`）には check の合否のみが残り、詳細の文字列やピクセル値は保存されないため、上の evidence は合否としきい値を書いている。
- スクリーンショットは初期カメラ（az 49°、el 28°、半径 6 km）で、北西から山頂を見下ろした構図。手前が雪の山頂、奥に緑の低山、その上に CSS の空。
- データの出典は AWS Open Data の Mapzen Terrarium（USGS 3DEP、パブリックドメイン / CC0）。
