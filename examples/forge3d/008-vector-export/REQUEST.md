# forge3d "Vector export" に対応する専用描画器

[Vector export](https://milos-agathon.github.io/forge3d/gallery/08-vector-export.html) は、地形を描いた画面からベクター（SVG）を書き出す例です。

この実装はルクセンブルクの領土・鉄道6路線・駅6点を Canvas 2D で描き、同じビュー変換を使って現在の画面と同寸法・同座標の SVG を文字列で書き出します。書き出しボタンで SVG をダウンロードできます。ドラッグパンとホイールズームを持ちます。

元例との同条件の速度・画面比較は未実施です。元例は Rust/wgpu、この実装は Canvas 2D です。

## データと帰属

- 領土・鉄道・駅: この例のために用意した例示ジオメトリ（forge3d-004 と同じ座標）。

## 計測

`bin/mfs bench forge3d-008-vector-export -n 3` を3反復した。画面は1024×768・DPR 1。Canvas 2D なので GPU 時間は取得できない（`gpu: n/a`）。

| 指標 | 結果 | 予算 |
| --- | ---: | ---: |
| 初回表示 p50 | 13.3 ms | 300 ms 以下 |
| 再描画 p95 | 0.25 ms | 2.0 ms 以下 |
| フレーム間隔 p95 | 10.44 ms | 20 ms 以下 |
| コード gzip | 3,429 B | 5,000 B 以下 |
| データ gzip | 415 B | 15,000 B 以下 |

画面ピクセルと SVG 書き出しの検証6項目は3反復すべてで通った。

## 実装のメモ

- 書き出しは DOM を経由せず文字列連結で行い、描画と同じ origin/scale を使う。
- 駅名は SVG の `<title>` に入れ、書き出し内容の検証に使う。
