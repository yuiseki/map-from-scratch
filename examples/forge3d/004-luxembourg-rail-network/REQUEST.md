# forge3d-004-luxembourg-rail-network

forge3d のギャラリー例「Luxembourg rail network」のように、ルクセンブルクの領土ジオメトリの上に、主要鉄道網（CFL）のベクターラインを重ね合わせた輸送オーバーレイ地図を表示したい。ドラッグでパン、ホイールで拡大縮小でき、ラインが地理座標に固定されて追従すること。外部ライブラリなし、Canvas 2D で最速・最小で実装する。
