# forge3d-003-swiss-landcover

スイスの地形に 2024 年の土地被覆を色で重ね、北西からの陰影で起伏が読めるようにする。国境の外は描かず、ほぼ真上から国全体を見せ、題、出典、凡例を付ける。ドラッグで回り、ホイールで寄れる。外部ライブラリなし。

## 元の例

- forge3d: [Swiss Land-Cover](https://milos-agathon.github.io/forge3d/gallery/03-swiss-landcover.html)
- 元の例は、スイスの DEM に土地被覆のラスタを不透明度 0.82 で重ね、太陽を方位 315°・高度 17° に置き、ほぼ真上 (仰角 90°、傾き 10°) から撮る。画像には題、凡例、出典が入る。出典は Sentinel-2 10m Land Use/Land Cover (Esri、Impact Observatory、Microsoft)。

## 設計

1. 格子は z8 の terrarium の画素そのもの。
   - スイスの範囲を覆う 829x533 (1 セル 418 m)。標高は terrarium の画素をそのまま使い、再標本化しない。
   - 国境の内側で 150 m 未満のセル (terrarium の欠損、4 セル) は周囲の平均で埋める。高さを 2.5 倍にしているので、欠損が穴として目立つため。
2. 土地被覆は元の例と同じ Esri の 2024 年版。
   - UTM 32T と 31T の 2 タイルを、gdalwarp で同じ格子に最頻値で集約する。
   - Cloud Optimized GeoTIFF なので、GDAL は 420 m に近い概観だけを HTTP の範囲指定で読む。10 m の 2 タイル (325 MB) は取らない。最初は丸ごと落とそうとして、約 100 KB/s で 1 時間近くかかる見込みだったのでやめた。
   - 国境 (Natural Earth 10m) を同じ格子に焼き、外側のセルを分類 0 にする。
3. 配るのは 1 セル 3 バイト (標高 16 bit と分類 8 bit)。
   - 色を焼かず、分類番号をパレット (uniform) で色にする。国境の外の 0 が続く部分はよく圧縮される。swiss.bin は 1,295 KB、gzip 723 KB。
   - 陰影も焼かない。頂点シェーダが前後左右の 4 回の高さ参照で法線を作り、フラグメントシェーダが元の例の太陽 (315°、17°) で明るさを掛ける。分類が読めるよう、いちばん暗い面でも 0.45 にしている。
   - 分類 0 の面は discard で捨てる。
4. 全体は 1 ドローコール (約 88 万三角形)。頂点バッファはなく、`gl_VertexID` から格子の位置を作る (forge3d-001 と同じ)。
5. 題、凡例、出典は HTML。凡例はデータにある分類と、その面積の割合をベイクで数えたもの。

## 計測結果

`bin/mfs bench forge3d-003-swiss-landcover -n 3` (1024x768、DPR 1、ANGLE / NVIDIA RTX 3060)。

| 項目 | 値 | 予算 |
| --- | --- | --- |
| 初回描画 first_frame_ms p50 | 64.6 ms | 600 ms |
| 再描画 redraw_ms p95 | 0.03 ms | 8 ms |
| フレーム間隔 frame_interval_ms p95 | 0.34 ms | 20 ms |
| コード gzip | 6,295 B | 9,000 B |
| データ gzip | 723,200 B | 760,000 B |
| 検証チェック | 5 / 5 PASS (3 回とも) | |

redraw_ms は CPU が描画命令を出し終えるまで、frame_interval_ms は vsync なしの rAF の間隔で、どちらも GPU の実行時間は含まない。88 万三角形を GPU が何 ms で描いているかは測っていない。

## 検証チェック

- `drawn-inside-the-border`: ベルンとルツェルンは描かれ (alpha > 200)、格子の矩形の中にあるが国外のミュルーズとアヌシーは描かれない (alpha 0)。
- `drape-shows-the-class`: 分類ごとに、格子の中央に最も近い 9x9 の一様なブロックへ寄り、中心の画素を、陰影の明るさを合わせたうえでパレットの最も近い色に当てる。7 分類すべて一致。
- `legend-matches-data`: 凡例の行と見本の色が、格子にある分類と一致し、割合の合計が 1。
- `orbit-turns-the-country`: 方位を 45° 回すとジュネーブが 100 px より大きく動く。
- `zoom-changes-scale`: ジュネーブとチューリッヒの画面上の距離が、半径を半分にすると 1.6 倍より大きくなる。

## 開発中に見つけたこと

- 凡例のチェックが、湿地 (8 セル) と雲 (1 セル) の抜けを見つけた。割合を小数 4 桁に丸めてから 0 より大きいものを残していたため、ごく小さい分類が凡例から消えていた。セル数で判定するよう直した。

## 元の例との違い

- 元の例はスイスの座標系 (EPSG:2056) の格子で描く。ここでは terrarium と同じ Web Mercator の格子にした。北緯 47 度前後の国 1 つの範囲では、形の違いは目で見て分からない程度。
- 元の例は DEM と土地被覆の解像度が高い (土地被覆は約 20 m)。ここでは 1 セル 418 m に集約した。
- 元の例は静止画 1 枚。ここでは回したり寄ったりできる。
- 汎用ライブラリや forge3d 本体とは、同じ条件で並べて測っていない。
